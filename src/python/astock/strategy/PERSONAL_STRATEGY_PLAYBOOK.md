# 全球机构策略：国内个人投资者操作手册

**数据截点：2026-08-15。** 本手册把公开可见的全球机构“母策略”翻译成
中国内地个人可审计的研究和纸面交易流程。它不是对任何机构专有模型、历史业绩、
产品适当性或未来收益的复制，也不会生成或路由任何订单。

## 1. 先区分“策略名称”与“可复制的经济引擎”

顶级机构公开披露的通常是策略类别、投资范围和风控框架，而不是可直接复制的信号、
数据、融资成本或执行算法。因此本手册采用四个状态：

| 状态 | 含义 |
| --- | --- |
| `已实现（纸面）` | 本仓库已有来源、时间点、风控和组合账本约束的策略引擎；仍不下单。 |
| `条件研究` | 在真实账户资格、合约/产品条款和授权数据满足后才能研究；当前不将其当成可交易目标。 |
| `研究框架` | 可借鉴尽调或组合构建方法，但无法声称复制机构回报。 |
| `不可等价复制` | 需要全球借券、PB 融资、低延迟执行、做市库存、期权曲面或私有交易权；不以简化替代品冒充。 |

公开策略参照：Bridgewater 的 All Weather/风险平衡框架、Man AHL 的系统化趋势、
AQR 的价值/动量/Carry/防御风格溢价、Citadel 的跨资产宏观与相对价值平台、
Two Sigma 的数据与系统化执行平台，以及 Blackstone/Apollo 的私募股权和信贷承销。
这些材料可说明“机构在做什么”，不能证明个人能获得相同回报。

## 2. 全球策略—国内市场—加密市场适用性矩阵

| 机构母策略 / 公开代表 | 经济引擎 | 国内证券及期货 | 加密市场 | 个人正确操作 |
| --- | --- | --- | --- | --- |
| 战略配置、风险平价（Bridgewater） | 将增长、通胀、流动性等风险来源分散，而不是预测单一市场 | `研究框架`：可用现金、合法 ETF、债券和黄金产品做风险预算；不能称为完整 All Weather | 不是加密资产配置理由 | 先把近期开支和保证金准备金从风险资本中分离；按共同 NAV 核算所有风险袖套 |
| 全球宏观 / 宏观相对价值（Bridgewater、Citadel） | 利率、汇率、通胀和政策预期的跨资产定价差 | `条件研究`：国内可做的范围受产品、外汇、期货资格和数据限制 | `研究框架`，不把代币价格当作宏观交易通道 | 先写情景、可观察变量与失效条件；不要把新闻判断直接变成高杠杆仓位 |
| 多市场 CTA / 时序动量（Man AHL） | 趋势在多品种、多个速度上延续；用波动率而非主观看涨看跌定仓 | `已实现（纸面）`：国内实际合约的低频 CTA | 在合法的非内地司法辖区仅可研究；24/7、资金费率和托管改变风险 | 每日收盘后以实际结算价更新，D+1 才可执行；先核验合约、保证金、限仓、换月和交割窗口 |
| 风格溢价 / 横截面因子（AQR） | 价值、质量、动量、投资、低风险等特征的长期分散暴露 | `已实现（纸面）`：A 股长多质量/价值/动量/投资倾斜 | `条件研究`：资产存活偏差、交易所/托管和做空限制很强 | 冻结时点一致的财务与交易状态数据，分行业、限流动性和单名权重；不要用“因子”掩盖追热点 |
| 基本面多空（Citadel 等） | 行业和公司基本面分歧，通过多空与风险中性表达 | `研究框架`：A 股仅做长多公开信息承销，不能假设可得到对冲空头 | `条件研究`，但交易所对手方、借币、清算和监管是独立风险 | 把空头和融资能力当作缺失，而非在净多组合中宣称“市场中性” |
| 财报后重定价 / 事件驱动 | 公开披露信息被市场逐步吸收 | `已实现（纸面）`：仅使用已经公开且已可得的财报信息 | `研究框架`：公告源、时间戳和操纵风险更强 | 记录发布时刻和可得时刻；确认超预期定义、流动性、停牌/涨跌停状态，再按预设期限跟踪 |
| 并购套利、特殊情形 | 交易条款、审批、融资和破约概率的情景定价 | `研究框架`：不产生无风险价差或空头对冲承诺 | 通常没有可靠等价物 | 只做文件时间线、条款和失败情景研究；不把“公告折价”当作必然套利 |
| 期限结构、Carry、跨期相对价值 | 为承担资金、流动性、交割和尾部风险获取补偿 | `条件研究`：需要近远月实际合约、交割、保证金、限仓与流动性事实 | 内地不作为实施路径；非内地也仅研究，资金费率/基差并非无风险收益 | 先做双腿数据质量和交割日历审计；没有真实双腿成本与保证金，就不生成价差信号 |
| 统计套利、配对交易、做市（Two Sigma 等） | 细微相对定价偏离和微观结构优势 | `不可等价复制` | `不可等价复制` | 不以相关性、单个均线或网格交易冒充机构统计套利；数据、借券、容量和执行是策略本体 |
| 波动率套利、指数成分股离散度 | 隐含波动、相关性与动态对冲的定价差 | `不可等价复制` | `不可等价复制` | 不用卖裸期权或单一波动率指标替代；需要完整曲面、Greeks、保证金和尾部流动性管理 |
| 私募股权运营承销（Blackstone、KKR、Carlyle、TPG） | 控制权、运营改善、资本结构和退出 | `研究框架`：转化为公开公司承销和长期跟踪 | 不适用 | 建立现金流、治理、竞争力、估值和失效条件清单；不要把“PE 思维”当成高估值买入理由 |
| 私募信贷 / 特殊信贷（Apollo 等） | 契约、担保、优先级、现金流覆盖和流动性溢价 | `研究框架`：只做产品条款和现金流尽调 | 不适用 | 逐项核对资产、优先级、费用、赎回、估值政策和违约处置；不以票息代替风险收益 |
| 基础设施 / 实物资产（Brookfield 等） | 长久期现金流、合同和资本开支周期 | `研究框架`：公开 REITs/基金要做产品级研究 | 不把 RWA 代币化视为内地个人通道 | 关注底层资产、租约/特许权、杠杆、估值和流动性，而非标签 |

## 3. 当前系统真正能运行的四个袖套

### 3.1 国内期货 CTA：多速度时序动量

**规则。** 对每个实际合约，以 60 日对数收益波动率 \(\sigma_{60}\) 规范化三种速度的
趋势分量：

\[
S_t=0.45\frac{\log(P_t/P_{t-21})}{\sigma_{60}\sqrt{21}}
+0.35\frac{\log(P_t/P_{t-63})}{\sigma_{60}\sqrt{63}}
+0.20\frac{\log(P_t/P_{t-126})}{\sigma_{60}\sqrt{126}}.
\]

它不是价格预测。系统以 \(S_t\) 的正负与进入/退出缓冲决定方向，再以波动率、每手保证金、
品种组风险、成交参与率和限仓决定整数手数。默认年化风险目标 10%，总保证金上限为共同
NAV 的 25%。默认新开仓要求 \(|S_t|\geq0.35\)，已有持仓在 \(|S_t|\leq0.15\) 时退出，
以减少阈值附近反复换向；信号只在收盘后形成，最早下一交易日生效。

**个人操作顺序。**

1. 从期货公司/交易所确认自己能交易的交易所与品种，并保留日期、来源和数据权限证明；
   有期货资格不等于对每个品种、每个交易所和每类数据都有资格。
2. 使用实际合约而非连续主力图：每个交易日都要有活跃合约、结算价、成交量、持仓量、
   到期剩余天数、交易状态、合约乘数、初始/维持保证金、限仓和来源。
3. 当活跃合约变化时，必须记录旧合约平仓价格、新合约开仓价格和换月来源；没有这些字段，
   历史 P&L 回放应被拒绝。
4. 将当天的纸面目标与前一日目标比较。入场/反转、退出、换月或流动性失败都要在下一可交易
   时段处理；涨跌停、停牌或保证金提高时不假设即时止损成交。
5. 先做跨周期、含成本、含滑点的走样本回放和纸面跟踪；任何人工操作都须在账户外独立确认。

### 3.2 A 股因子倾斜：长多而非“市场中性”

**规则。** 复合分数为 \(0.30Q+0.25V+0.25M+0.20I\)：质量、价值、动量、投资四项
输入均须是当时可得的、已标准化的研究字段。候选股必须被验证为
沪深北 A 股，有时区的当前交易状态，满足成交额和上市天数要求，并通过停牌、风险警示、
涨跌停及流动性否决。默认最多 20 个持仓、总权重 40%、单名 6%、单行业 25%。

**个人操作顺序。** 在预先固定的频率（如月度或季度，频率本身也应先回测）冻结当时可得
的财务和交易数据，生成横截面排序，再按行业与流动性约束分配权重。不要把今天修订后的
财报、退市名单或行业分类塞回过去的回测。A 股的 T+1、停复牌和涨跌停意味着“触发止损”
不是保证能成交的机制。

### 3.3 财报事件重定价：时间戳比“好消息”更重要

**规则。** 系统只接受有不可变公告标识、发布时间和实际可得时间的事件，且两者均不得晚于
策略截点；默认只保留五日内、惊喜分数至少 0.50、流动性合格且交易状态可执行的候选项。
默认总权重 20%、最多 12 个、单名 8%、单行业 30%。

**个人操作顺序。** 先定义市场预期的来源和“超预期”公式，再记录公告何时进入公开渠道；
把“公司叙事很好”与“本期财报超出预期”分开。持有期限、减仓条件和下一次业绩验证条件
要在建仓研究阶段写清，不能事后追认。

### 3.4 共同 NAV 风控：先算抵押品，再谈收益

系统把权益、期货和（在合规司法辖区才可能研究的）加密资产放入同一个现金与抵押品瀑布，
先按整数手数计算期货保证金，再给现金资产分配剩余资金。默认总权益上限 70%、期货保证金
上限 25%。这是**系统保护阈值，不是个人配置建议**。任何硬风险否决都会冻结新目标，
而不是把风险资产静默抵消。

## 4. 加密市场：经济上可能，内地不作为实施路径

趋势、横截面动量和事件研究可以在加密价格序列上做研究，但它们不自动成为可投资策略：
24/7 交易、交易所/托管对手方、稳定币、资金费率、清算瀑布、资产存活偏差和市场操纵都
会改变回测含义。

本系统的加密研究模块要求：带时区的 OHLCV 与可得时间、交易所与市场类型、不可变数据
归档、永续合约的已验证资金费率，以及非内地司法辖区的日期化合规、场所、托管和数据权限
证据。即使满足这些条件，输出仍为研究/纸面目标。

对于中国内地居民，本手册不把加密资产、境外交易所、VPN、代持或稳定币转换当作实施方案。
2026 年 2 月的联合通知明确，境内虚拟货币相关业务活动严格禁止，并禁止境外主体非法向
境内主体提供相关服务。该通知不是对个人事实的法律意见；任何跨境、税务、身份或产品问题
都需要当前、独立的专业意见。

## 5. 个人投资者的完整操作流程

1. **写下账户边界。** 分开生活现金、可承受损失的风险资本、期货保证金储备和不允许使用的
   杠杆/品种；不要从策略历史收益倒推风险承受能力。
2. **冻结策略定义。** 在看结果前固定标的池、信号、再平衡频率、成本、滑点、风险上限、
   失效条件和数据来源；版本化保存。
3. **验证时点和合约事实。** 每条数据都回答“它在当时是否真的可得”“这个合约当时能否交易”
   和“价格、保证金、持仓限制来自哪里”。
4. **先做走样本和压力测试。** 覆盖至少不同波动、趋势、震荡、流动性收缩和涨跌停/换月情景；
   结果须包含费用、滑点、空仓和无法成交的日期，而不是只报告夏普比率。
5. **纸面运行和对账。** 观察信号、目标、实际可交易性、保证金和预期/实际偏差。出现数据质量、
   资格、交割、流动性或风险预算问题时冻结，而不是“补一个估计值”。
6. **人工决策仍在系统外。** 本仓库只提供研究和纸面账本；它不连接券商、期货公司、交易所、
   交易所钱包或托管机构。
