# 上游资源安全与基准现金流证据

门禁状态：有条件通过。本包把钨矿山/钨精矿、APT/粉末加工、萤石/AHF、制冷剂HFC配额和一体化氟化工证据合并，回答“上游利润池是否有可量化兑现基础”。结论是：钨资源、萤石/AHF和制冷剂配额可以进入基准业务现金流或资源安全溢价；但这些证据仍不得替代半导体高纯钨材、WF6/NF3或含氟电子材料的客户订单、合同平均售价、收入确认比例、单品收入和单品毛利。

- 覆盖标的：8只。
- 可进入资源/配额基准现金流：7/8。
- 可进入半导体或电子材料增长每股收益：0/8。
- 使用边界：本包把钨、萤石、AHF和HFC配额的资源/供给安全证据压成基准业务门禁；资源和配额可进入基准现金流或资源安全溢价，但不关闭半导体高纯钨材、WF6/NF3或含氟电子材料的订单、平均售价、收入和毛利缺口。
