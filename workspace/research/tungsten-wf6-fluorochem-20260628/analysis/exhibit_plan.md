# 图表架构计划

门禁状态：通过。本计划覆盖正文和附录的核心图表/表格，目标是让每一个强结论都有对应图表或表格支撑，并且每个图表/表格都有投资含义。

## 架构原则

1. 首页只放能直接支持投资决策的表：排序、价格、目标价、空间、二季度验证和高成长门禁。
2. 产业链章节先定义利润池，再给公司映射，最后进入客户链声明审计。
3. 估值章节不只给目标价，还要给供应链信用、增长每股收益门禁、情绪锚和失效条件。
4. 长来源表和模型假设放入附录，正文只保留投资判断需要的证据。
