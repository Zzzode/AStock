# Gate manifest

This is a **strategic-allocation research framework**, not an issuer report or a live allocation. Scope, implementation and execution remain inactive: `q=0`, no named direct equity is in the decision universe, and no public REIT is activated. The machine-readable controls, required artifacts, review cycles, pass conditions and downgrade path are in `gate_manifest.json`.

The key publication test is not whether the memo is enthusiastic about private equity. It is whether it makes the distinction between transferable underwriting discipline and non-transferable institutional privilege explicit, evidence-indexed and operationally useful.
