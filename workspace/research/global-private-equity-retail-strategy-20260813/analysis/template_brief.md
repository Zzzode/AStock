# Template brief — PE-style public-market underwriting

## Report archetype

Strategic evidence memo. The decision is whether a method is transferable, not whether a named asset should be purchased.

## Reader promise

The report makes four distinctions visible:

1. manager business-model facts versus claims of repeatable excess return;
2. public-information discipline versus control, access and leverage privilege;
3. a process gate versus a personalised allocation;
4. a fundamental thesis failure versus ordinary mark-to-market volatility.

## Core visual sequence

1. conclusion dashboard;
2. seven-manager method matrix;
3. transferability ladder;
4. five-vote underwriting gate;
5. China-market constraint map;
6. monitoring / failure timeline;
7. red-team objections and source audit.
