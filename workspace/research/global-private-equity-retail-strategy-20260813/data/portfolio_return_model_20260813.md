# Future-activation model — deliberately inactive

The only active row is a generic protected-liquidity placeholder at 100%; it is **not** a named product recommendation. Every market-traded sleeve is `q=0` because no investor data, ticker, current price, liquidity, tax, account or suitability record has been supplied.

The framework has no return forecast or required income target. A later named security needs the complete direct-equity or public-REIT activation dossier in the paired JSON. The cash and total-return formulas explicitly prevent double counting and prohibit leverage as a repair mechanism.
