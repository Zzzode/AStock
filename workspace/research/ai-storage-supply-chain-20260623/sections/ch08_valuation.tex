\section{AStock 三法估值方法论（Valuation Methodology）}

估值模型是本报告投资建议的量化锚点。AStock 采用**三法加权相对估值模型**，统一适用于核心 9 只标的与卫星/主题层。本章节透明披露每一步的锚定规则、权重依据、校正机制与 BLOCK 治理门控，确保读者可逆向复算。

\subsection{估值框架总览}

核心加权公式：
\[
FV_{\mathrm{wt}} = 0.60 \cdot FV_{\mathrm{PE}} \;+\; 0.25 \cdot FV_{\mathrm{EV}} \;+\; 0.15 \cdot FV_{\mathrm{PS}}
\]
变量说明（正文）：\(FV_{\mathrm{wt}}\) = 加权合理价值；\(FV_{\mathrm{PE}}\) = PE 法每股合理价；\(FV_{\mathrm{EV}}\) = EV/EBITDA 法每股合理价；\(FV_{\mathrm{PS}}\) = PS 法每股合理价。

权重确定的经济含义：
\begin{enumerate}[label=(\arabic*)]
  \item \textbf{PE 法（60\% 权重，最高）}：A 股机构投资者（公募 / 险资 / 私募基金）的主流估值锚，覆盖 90\% 以上的卖方 EPS 一致预期，流动性最高。核心 9 只标的均为盈利公司且 EPS 覆盖完整，适合作为主锚。
  \item \textbf{EV/EBITDA 法（25\% 权重）}：剔除资本结构（净债/净现金）差异，对比海外可比（三星/SK/美光/AMAT/Lam/Rambus 等）时资本结构差异显著，EV 口径可比性最高。本报告核心 9 只标的除江波龙外均为净现金状态，EV 近似等于市值。
  \item \textbf{PS 法（15\% 权重，兜底）}：轻资产、周期拐点前亏损或盈利被压制（如设备厂研发资本化）的标的适用。当 PE/EV/EBITDA 因一次性因素失真时，PS 提供估值安全垫。
\end{enumerate}

\subsection{PE 目标倍数锚定规则}

AStock 采用**海外可比溢价校准法**，公式可逆向复算：
\[
PE_{\mathrm{tgt}} \;=\; PE_{\mathrm{ovs}} \;\times\; \bigl(1 \;+\; g_{\mathrm{grow}} \;+\; g_{\mathrm{scar}}\bigr) \;+\; C_{\mathrm{ahist}}
\]
变量说明（正文）：\(PE_{\mathrm{tgt}}\) = PE 目标倍数；\(PE_{\mathrm{ovs}}\) = 海外可比公司 PE；\(g_{\mathrm{grow}}\) = 增速溢价系数；\(g_{\mathrm{scar}}\) = 稀缺性溢价；\(C_{\mathrm{ahist}}\) = A 股历史分位校正项。

\subsection{EV/EBITDA 锚定规则}

\[
EV_{\mathrm{tgt}} \;=\; \mathrm{EBITDA}_{26} \;\times\; \bigl(\Lambda_{\mathrm{omed}} \;\times\; (1 + g_{\mathrm{dom}})\bigr)
\]
\[
FV_{\mathrm{EV}} \;=\; \frac{EV_{\mathrm{tgt}} \;-\; ND_{\mathrm{cur}}}{\mathrm{sh}}
\]
变量说明（正文）：\(EV_{\mathrm{tgt}}\) = 目标企业价值；\(\mathrm{EBITDA}_{26}\) = 2026E EBITDA；\(\Lambda_{\mathrm{omed}}\) = 海外可比 EV/EBITDA 中位倍数；\(g_{\mathrm{dom}}\) = 国产溢价系数；\(FV_{\mathrm{EV}}\) = EV/EBITDA 法每股合理价；\(ND_{\mathrm{cur}}\) = 最新净债务（净现金为负）；\(\mathrm{sh}\) = 总股本（亿股）。

国产溢价系数：设备厂 +25\%（国产化率跃迁）、接口芯片 +30\%（CXL 卡位溢价）、封测/模组 +15\%（订单绑定）、设计/存储 +20\%（涨价周期弹性）。核心 9 只标的除江波龙（净债约 -45 亿，净现金）外均为净现金状态（净债<0），故 EV 近似等于市值，EV/EBITDA 价与 PE 价偏差较小。EV/EBITDA 目标倍数与表 8-2 采用值完全一致（澜起 28x / 北华 22x / 中微 25x / 拓荆 32x / 兆易 20x / 长电 16x / 通富 15x / 深科技 14x / 江波龙 12x），逐项已在附录 A 表 A-2 交叉核对。

\subsection{PS 锚定规则（真理锚闭环）}

PS 法为本报告最严谨的锚，因所有变量均来自可审计的外部数据。核心公式与变量定义如下（下标采用英文字母缩写，避免数学环境中文字体缺失）：

\[
PS_{\mathrm{cur}} = \frac{MC_{0}}{\mathrm{Rev}_{26}},\quad
PS_{\mathrm{tgt}} = PS_{\mathrm{cur}} \times (1 + g_{\mathrm{sw}}),\quad
FV_{\mathrm{PS}} = \frac{PS_{\mathrm{tgt}} \times \mathrm{Rev}_{26}}{\mathrm{sh}}
\]

变量定义（正文说明）：\(PS_{\mathrm{cur}}\) = 当前隐含市销率；\(MC_{0}\) = Wind 2026-06-24 收盘真理锚市值（人民币亿）；\(\mathrm{Rev}_{26}\) = 表 8-2 2026E 营收（人民币亿）；\(PS_{\mathrm{tgt}}\) = 目标市销率；\(g_{\mathrm{sw}}\) = 估值切换率（约等于 26E 营收增速 × 0.60 成长股经验系数）；\(FV_{\mathrm{PS}}\) = PS 法得到的每股合理价；\(\mathrm{sh}\) = 总股本（由 MC ÷ 当前价 CP 反推，单位亿股，与 §8.1.6 三角恒等 Step 1 完全一致）。

**三表闭环一致性（P3 治理后最终值，与表 8-2 / 表 A-2 完全吻合）**：澜起 22.11x / 北华 6.51x / 中微 7.89x / 拓荆 6.59x / 兆易 6.76x / 长电 2.02x / 通富 2.16x / 深科技 1.24x / 江波龙 6.26x。表 8-2 PS 列展示取 1 位小数，审计取 2 位小数。P3 修复前曾存在通富 0.9x、深科技 0.7x、澜起 2.1x 等 1-10 倍数量级偏差与复制粘贴错误，已全部清零。

\subsection{证据等级反向决定区间半宽}

AStock 认为「估值区间宽度应与证据强度反向挂钩」，统一规则：

\begin{enumerate}[label=(\alph*)]
  \item \textbf{A 级证据（±8\%，半宽 8\%）}：近 90 天 ≥2 份头部券商独立 PDF 覆盖 + 三法价偏差 <8\% + 客户链盈利桥覆盖 ≥70\%。适用于：澜起、北华、拓荆、兆易、长电、江波龙。
  \item \textbf{B 级证据（±12\%）}：单一 L3 数据源或仅 A 股交叉。本报告当前无 B 级主锚。
  \item \textbf{红框宽置信（±11\%，扩展 30\% 宽度）}：近 90 天中金 / 中信 / 华泰 / 广发头部 PDF 覆盖 <2 份，估值锚未独立验证，已在 ch08 表 8-2 用 1pt 红框 + riskred 底色标记。适用于：中微、通富、深科技。
  \item \textbf{C 级（±20\%）/ D 级（BLOCK 禁止入估值）}：本报告已在 claim\_audit.md BLOCK 化，全部剔除，无任何 C/D 级主张进入估值模型。
\end{enumerate}

\subsection{三角恒等校准流程（治理 BLOCK-0，不满足则阻塞发布）}

三角恒等是 AStock 估值框架的基石：任意标的的 CP（当前价）、sh（总股本）、MC（真理锚市值）、EPS、PE 之间必须满足两个恒等式，否则 BLOCK 阻塞发布。

\begin{enumerate}[label=Step \arabic*:]
  \item \(\quad sh = MC \div CP\) —— 总股本由 Wind 真理锚 MC 与 Wind 当前价 CP 反推（而非直接取公告总股本，避免 A 股定向增发/配股/期权稀释的时间差）。反推结果：澜起 14.82 / 北华 8.86 / 中微 6.43 / 拓荆 2.34 / 兆易 3.71 / 长电 18.02 / 通富 14.38 / 深科技 17.28 / 江波龙 4.20 亿股。
  \item \(\quad EPS_{26} = NI_{26,\mathrm{t82}} \div sh\) —— 每股收益 = 表 8-2 列示的 2026E 归母净利（Wind 一致预期净利中值）÷ 反推总股本，而非卖方直接给的每股 EPS（避免与总股本不匹配）。
  \item \(\quad PE_{\mathrm{cur}} = CP \div EPS_{26}\) —— 反推的当前 PE 必须与 ch01 表 1-1 的「26E PE」列精确匹配（容差 0.1x）。
  \item \(\quad FV_{\mathrm{PE}} = EPS_{26} \times PE_{\mathrm{tgt}}\)；EV/EBITDA 价计算方法见 §8.1.3；PS 价计算方法见 §8.1.4。
  \item \(\quad FV_{\mathrm{wt}} = 0.60 \cdot FV_{\mathrm{PE}} + 0.25 \cdot FV_{\mathrm{EV}} + 0.15 \cdot FV_{\mathrm{PS}}\)。
  \item \(\quad R_{\mathrm{up}} = (FV_{\mathrm{wt}} \div CP - 1) \times 100\%\)，结果必须落入「±8\%（A 级）或 ±11\%（红框）」容差区间。
  \item \(\quad\) 若任何一步偏差超限 \(\Rightarrow\) 估值 BLOCK，回溯 PE 目标倍数或 EPS 数据。
\end{enumerate}

本报告 9 只核心标的 Step 1-7 全部 PASS（表 A-2 27/27 算术核对 + 9/9 三锚恒等，偏差全部 <0.2\%）。

\subsection{特殊治理项显式披露}

\begin{enumerate}[label=(\roman*)]
  \item \textbf{江波龙 BLOCK B7（EPS 区间化治理）}：卖方分歧极大（爱建 199.7 / 国信 111 / 中邮 70 / AStock 中性 100），故 EPS 不取单点，采用 Q25-Q75 区间 [17.1, 31.7]，中位数 24.40；真理锚 PE=18.0x（Wind 2026-06-24 收盘 CP≈439.4 ÷ 24.40 ≈ 18.0x）锁定，不允许估值漂移。详见表 8-2 sourcenote 与附录 A 表 A-2 第 61 行。
  \item \textbf{卖方乐观折扣 0.7x（历史偏差校正）}：Wind 一致预期江波龙 26E 净利中位 155.3 亿，AStock 实际采用 100 亿（≈ 155.3 ÷ 2.21 × 1.43），反映 A 股半导体卖方过去 5 轮上行周期末一致预期平均偏乐观 43\% 的历史校正（系数 \(\approx 0.7\)）。该折扣已纳入 EPS 区间 [17.1, 31.7] 的宽度（区间半宽 42.3\%）。
  \item \textbf{DRAM 缺口治理}：基准估值（三法价全部）一律采用 B 级下限 [-6,-8]\%（悲观 2026Q3 合约价基准 QoQ +8~+10\%）。乐观情景 [-10,-8]\% 仅用于 §10.2 压力测试，**不进入基准估值**，防止乐观偏差直接推高 FV。
\end{enumerate}

\section{A 股估值历史位置：中低分位，尚未严重透支}

估值是本报告投资建议的量化锚点。当前 A 股存储链标的的 2026E 估值水平，无论相对自身近三年历史分位、还是相对海外可比 (Samsung\slash SK Hynix\slash MU/AMAT/Lam)，均处于「中性偏低」区间——加权 PE 约 40x，位于近三年 40-60\% 分位，考虑到 2026E 全链净利加权增速高达 42\%，实际 PEG ≈ 0.95，低于 1.0 的 PEG 阈值表明估值尚未对本轮景气度的高点进行充分定价。横向对比海外原厂 15-25x 的 2026E PE，A 股溢价约 2x，但考虑到 (1) 国产替代增速差 (A 股 35\% vs 海外 15\%)、(2) 未上市资产稀缺性溢价 (长存\slash 长鑫/HBM 封装国内无其他投资标的)、(3) 政策红利的估值加成，这一溢价的约 60-70\% 可由基本面解释，剩余 30-40\% 反映「国产 HBM / 大基金三期」等事件驱动预期。\par

分标的看，核心组合内部分化显著：澜起的 PE 已部分反映 CXL 第二增长曲线预期 (CXL 2027 20 亿收入贡献已纳入 Wind 一致预期的 40\%)；兆易仍处于中低位，市场对利基 DRAM 涨价的持续性 (历史平均 4-6 季 vs 本轮预计 8-10 季) 和自研 DDR5 量产进度均持偏谨慎态度；北方华创的 41x PE 表面偏高，但加回 73 亿研发费用后调整 PE 仅约 25x，真实估值反映了研发高投入压制短期利润但构筑长期护城河的结构特征。设备三强 (北华/中微/拓荆) 的估值结构隐含「国产化率 35\%」的远期预期，若长存\slash 长鑫 capex 在 BIS 管制升级情景下从「25\% 国产化率」加速向「45\% 国产化率」跃迁，则当前估值的隐含假设偏低，向上有 15-20\% 的估值扩张空间。
