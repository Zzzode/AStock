### B-1. [ch02_executive_summary.tex:40-50] 图2-1 House View 子论点框垂直重叠
**维度**：L-2 重叠  
**检测探针**：TikZ 坐标几何推演 — y 坐标区间重叠计算  
**严重性**：BLOCK（核心观点图视觉崩溃）

**问题描述**：
- sub1 节点 y=2.15, minimum height=1.1cm → 垂直区间 [1.60, 2.70]
- sub2 节点 y=1.50, minimum height=1.1cm → 垂直区间 [0.95, 2.05]
- **重叠区间 [1.60, 2.05] = 0.45cm**，若 sub1 因 3 行文字扩展，重叠可达 0.55cm

**修复代码**：
```latex
% 当前（错误）：
\node[subpoint] (sub1) at (4.5, 2.15) {...};
\node[subpoint] (sub2) at (4.5, 1.50) {...};

% 修复：增大 y 间距至 ≥ 1.4cm（1.1cm min height + 0.3cm 安全间隙）
\node[subpoint] (sub1) at (4.5, 2.6) {...};  % 原 2.15 → 2.6
\node[subpoint] (sub2) at (4.5, 1.1) {...};  % 原 1.50 → 1.1
% sub3 同步调整
\node[subpoint] (sub3) at (4.5, -0.4) {...}; % 原 0.05 → -0.4
```

**验收标准**：子论点框间垂直间隙 ≥ 0.3cm

### B-2. [ch10_risk_stress.tex:48-50] 图10-1 风险矩阵 R3 与 R5 气泡相切
**维度**：L-2 重叠  
**检测探针**：圆心距 vs 半径和几何计算  
**严重性**：BLOCK（风险矩阵两个独立风险无法区分）

**问题描述**：
- R3 气泡：center=(3.0, 5.5), minimum size=2.0cm → 半径=1.0cm
- R5 气泡：center=(4.0, 4.0), minimum size=1.6cm → 半径=0.8cm
- 中心距 = √((4.0-3.0)² + (4.0-5.5)²) = √(1.0+2.25) = √3.25 ≈ **1.80cm**
- 半径和 = 1.0 + 0.8 = **1.80cm**
- **间隙 = 0cm**，两气泡边缘完全接触。若任一气泡因文字扩展，立即重叠

**修复代码**：
```latex
% 当前（相切）：
\node[bubble, ...] (R3) at (3.0, 5.5) {...};
\node[bubble, ...] (R5) at (4.0, 4.0) {...};

% 修复：将 R5 向右下移动，确保间隙 ≥ 0.3cm
% 需要中心距 ≥ 1.8 + 0.3 = 2.1cm
\node[bubble, ...] (R5) at (4.3, 3.7) {...};  % 原 (4.0,4.0) → (4.3,3.7)
% 新中心距 = √(1.3²+1.8²) = √(1.69+3.24) = √4.93 ≈ 2.22cm ✓
```

**验收标准**：R3-R5 气泡间隙 ≥ 0.3cm

- 影响全部 5 个 hyperscaler（MS, META, GOOGL, AWS, BYTE）的 Capex 传导箭头

**修复代码**：
```latex
\foreach \h in {MS,META,GOOGL,AWS,BYTE} {
  \draw[arrow] (\h.south) |- (L2.north);  % 先垂直后水平正交连接
}
```
