## Source-quality vocabulary

The catalog uses only these values: `original_pdf`, `broker_official_page`, `auditable_consensus_snapshot`, `abstract`, `media_repost`, `third_party_preview`, `search_snippet`, and `not_found`.

- `original_pdf`: complete, dated sell-side PDF archived in this directory.
- `broker_official_page`: an attributable broker-origin page; none was used in this collection.
- `auditable_consensus_snapshot`: a structured public consensus table that identifies broker, report date, rating and visible fields; none was found.
- `abstract`, `media_repost`, `third_party_preview`, `search_snippet`: discovery evidence only and zero weight for consensus/valuation.
- `not_found`: a documented unavailable result, not an inferred negative conclusion.
