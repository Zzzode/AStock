# Artifact Contract

机器可读的字段级契约见 `artifact_contract.json`。所有条目均规定了责任技能/角色、必填字段、最低深度、阻断条件、审阅周期与验收方式；以下为读者导向索引：

| 阶段 | 核心产物 | 最低要求 | 阻断条件 |
|---|---|---|---|
| R0 | 已核验财务与市场数据 | 披露期、来源、股本和市值口径一致 | 无来源的盈利或股本口径 |
| R0 | 来源登记、主张审计、券商包 | 客户、平台、订单、ASP 与目标价逐条分级 | 弱来源被用于估值权重 |
| R0 | 价值链与客户链 | 价值量至利润转换、缺口及降级触发 | 只有主题叙事却给估值信用 |
| R0 | Physical AI证据与机会树 | 一手产品/IR/生态来源、三层路径、客户至现金的断点 | 把合作、定点、POC或未具名订单写成收入/利润 |
| R1 | 增长盈利桥 | 基础业务与增长业务、情景和当前价隐含要求 | 单季年化或未桥接的高增长假设 |
| R1 | Physical AI条件价值 | 收入--净利--EPS--每股价值敏感性与明确概率门槛 | 主观概率或敏感性被偷渡进基础目标价 |
| R1 | 估值模型与审计 | 多锚目标、三情景、可复算 | 不可复算或直接照搬券商目标价 |
| R2-R3 | PDF 与视觉审阅 | 中文、叙事主导、结论均有证据图表 | 表格堆砌或版式缺陷 |
| R4 | 终签 | R0-R4 闭环与同版本验收 | 存在开放 S 级或未豁免 A 级问题 |
