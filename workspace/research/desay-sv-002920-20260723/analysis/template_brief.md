# Template Benchmark Brief

- **基准原型：** J.P. Morgan 单票权益研究报告；参考 `workspace/templates/global-broker-research/deep_template_analysis.md` 中的首屏投资仪表盘、营运驱动页、估值桥和评级风险框。
- **覆盖包：** custom：智能汽车电子与软件定义汽车。现有覆盖包未直接适配汽车 Tier-1；本案例在正文中采用以下强制模块：上游算力/感知与软件、中游座舱/智驾/域控、下游 OEM/车型平台、汽车电子价值量与盈利池、竞争/国产化、客户链与量产节奏、估值与二级市场。
- **首页仪表盘：** 价格与时点、行动标签、三档目标、核心论点、下一季阈值、上/下行触发、证据质量；不以券商摘要取代本院判断。
- **章节次序：** IC 摘要 → 公司与技术架构 → 产业/客户链 → 财务与增长盈利桥 → 竞争与市场预期 → 估值 → 风险与监测 → 来源说明。
- **必备展品：** 平台架构图、收入/利润/毛利率桥、价值量—收入—利润桥、竞争地图、情景估值与目标价权重、催化剂/反证时间线。
- **禁止事项：** 连续表格页、将 OEM/芯片平台视作收入证明、将市场传闻作为订单事实、将单季利润直接年化为估值分母、用单一券商目标替代本院估值。
