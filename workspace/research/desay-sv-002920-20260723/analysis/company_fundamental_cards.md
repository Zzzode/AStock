# 公司基本面卡：德赛西威（002920.SZ）

## 核心卡片

| 字段 | 审计结论 |
|---|---|
| 链条角色与直接性 | 汽车电子 Tier-1，直接受益于其已量产的智能座舱、智能驾驶与网联服务；不是上游芯片或显示材料受益标的 |
| 产品/过程暴露 | 座舱（IVI、显示、HUD、座舱域控、AI 座舱）、智驾（域控、传感器、算法、3D/4D 雷达、舱驾融合）、网联（基础软件、OTA、智能进入） |
| 上游输入依赖 | 高算力 SoC、存储、显示/光学、摄像头/雷达、连接器与软件工具链；Qualcomm G10PH 和 NVIDIA/小鹏 P7 的具体协作可验证，其余采购关系与价格 `not disclosed` |
| 下游证据 | 年报称与 80+ OEM 合作；第四代座舱在理想、小米、吉利、奇瑞、广汽配套；智驾域控在小米、理想、长城、小鹏、吉利、广汽丰田、东风日产、奇瑞、广汽本田等大规模量产；具体车型和客户收入未披露 |
| 收入与产品结构 | 2025 年收入 CNY32.557bn：座舱 CNY20.585bn/63.23%，智驾 CNY9.700bn/29.79%，网联及其他 CNY2.272bn/6.98%；客户/车型/产品 ASP `not disclosed` |
| 毛利与成本 | 汽车电子毛利率 19.07%；座舱 18.83%；智驾 16.36%（同比 -3.55pct）；原材料占营业成本 91.78%。毛利变动不能被单一平台升级解释 |
| 订单/认证/产能 | 新项目订单年化销售额 >CNY35bn（座舱 >CNY20bn、智驾 >CNY13bn）；订单年化不等于 backlog 或收入。ASIL D 相关产品认证及工厂进展有披露；各项目认证、设计产能、利用率和良率 `not disclosed` |
| 营运资本与现金流 | 应收账款 CNY9.778bn、存货 CNY4.789bn、合同负债 CNY1.005bn；经营净现金流 CNY2.884bn。审计报告提示按订单生产且专用度高，车型不利时有存货减值风险 |
| 研发与资本开支 | 2025 研发投入 CNY2.637bn（收入 8.10%）；购建固定资产、无形资产及其他长期资产支付现金 CNY1.803bn。研发投向/海外工厂可增强能力，但不能直接折算为收入 |
| 护城河 | 系统集成、软硬件协同、功能安全、客户项目交付和全球制造网络；仅以已披露量产/客户事实描述，不以市场份额宣称护城河 |
| 替代风险 | OEM 自研、其他 Tier-1 打包报价、SoC 平台迁移、BOM 成本、项目定价、海外爬坡及客户车型表现 |
| 估值相关性 | 可估已确认分部收入、毛利、现金流和营运资本；中央计算、第五代座舱、雷达、AR-HUD、区域控制器等均为可选性，直至提供客户/SOP/ASP/收入证据 |
| 核心池决定 | `eligible`，但限于**分部汇总历史和保守情景**；客户/车型/订单/ASP 驱动的增量模型为 `watchlist only / insufficient customer evidence` |
