# Segment Valuation Model

The correct classification is a diversified cyclical cable and safety platform.

| Component | Method | Denominator | Weight |
|---|---|---|---:|
| Core earnings | adjusted PE | 2026E adjusted parent EPS | 50% |
| Balance sheet check | PB | Q1 parent BPS CNY2.0490 | 25% |
| Revenue sanity check | PS | 2026E revenue | 25% |

No AI/data-center multiple is applied to consolidated revenue because the
company does not disclose segment purity, customer allocation, ASP or utilization.

## SOTP / Net Profit Sensitivity

This is not a pure SOTP because the company does not disclose H1 segment net
profit. The base consolidated net profit denominator is CNY5.20 hundred million
adjusted parent profit. A direct segment SOTP would create false precision, so
the model uses a blended PE/PB/PS cross-check instead.

| Input | Bear | Base | Bull |
|---|---:|---:|---:|
| Adjusted net profit (CNY100m) | 3.40 | 5.20 | 7.00 |
| PE | 25x | 34x | 44x |
| Sensitivity target | CNY5.07 | CNY9.16 | CNY14.96 |

## Validation Trigger

Upgrade from the blended model only when the H1 report provides optical and
safety segment revenue, net profit, gross margin, order visibility and cash
conversion. If those fields remain undisclosed, retain the current method and
do not assign a pure-growth multiple.
