估值看板是全报告的行动中枢：把技术、客户链和财务交付统一成可执行的投资判断。本章开篇即给出全产业链25只标的的估值速查表，使投资者一眼看清每只标的的评级、价值区间、估值水位和操作动作；后续小节再分别展开核心标的深度估值、券商模型与盈利预测、历史估值分位、敏感性框架和情景区间。

全章的核心纪律是\textbf{证据边界决定估值精度}：核心6家有完整目标PE带与合理价值区间，证据强度最高；扩充标的（Core Candidate + Watchlist + 设备耗材）给出参考价值区间与结构化定位，精度次之；需求指标与港股锚不纳入目标价体系，仅作产业链参照。三层不可混用。

\begin{sourcequalitybox}[估值边界]
本报告不给出伪精确的单点目标价，而是基于公开行情、券商模型区间和AStock情景判断给出合理价值区间、估值空间和投资动作。价格锚取腾讯公开行情：2026年6月18日抓取到12只标的最新返回价格、总市值、PE和PB，内嵌时间戳为2026年6月17日16:14前后。该快照是公开行情返回值，不是Wind/Choice标准化估值库；所有结论均需在正式投资决策前用最新收盘价和公司公告复核。扩充标的参考区间为PE$\times$EPS机械推导（非券商目标价），Q2E为Q1年化口径（非单季模型）；具体假设见本章"扩充标的估值方法说明"小节。
\end{sourcequalitybox}

估值结论必须从"盈利能否兑现"出发，而不是从主题热度出发。当前半导体PCB链条的共同问题是：2026--2028年盈利预测普遍给了较陡的增长曲线，但股价也已经提前反映了很大一部分预期。因此，合理估值不能只看目标价上行空间，还要同时看三个约束：第一，2026Q2是否能延续Q1的收入和利润节奏；第二，毛利率是否由高端产品结构真实驱动，而不是短期价格波动；第三，客户链证据是否足以支撑给更高倍数。

\begin{sourcequalitybox}[三层估值体系提示]
\textbf{市场上同时存在三层估值体系，水平差异极大，投资者不可混淆。}
（1）\textbf{东方财富一致预期}（图表第6列）：国内多家券商公开目标价的聚合区间，偏传统行业估值框架，对AI主题溢价反映较慢，多数标的为10--30x PE水平，是全市场最保守的一层。
（2）\textbf{本报告合理价值区间}（图表第5列）：在传统估值基础上，计入已验证的AI订单、国产替代卡位和高端产品结构升级溢价，PE带显著高于行业历史中位，但仅使用已兑现的证据（已量产/已认证/已交付），不包含未兑现的叙事期权。
（3）\textbf{外资投行具名目标价}（操作建议列【外资】标签）：高盛、花旗、摩根大通等外资行给出的目标价，普遍隐含2027--2028年高增长延续+科技周期溢价，是最激进的一层，与生益科技等标的的一致预期差距可达100\%以上。
三层估值依次抬升，反映的是从"已发生"到"将发生"的预期递进。投资者应根据自身风险偏好和验证节奏，选择对应层级作为决策锚。
\end{sourcequalitybox}

\section{估值体系分层与差异原因}

当前半导体PCB产业链同时存在三层估值体系，水平差异极大，从最保守的一致预期到最激进的外资目标价，价差可达100\%以上。投资者必须清楚自己在使用哪一层估值，以及该层估值对应的假设和风险。图表8-1同时展示了前两层（本报告估值 + 东方财富一致预期），并在操作建议列标注了第三层（外资具名目标价），三者关系如下。

\subsection{第一层：东方财富一致预期——传统行业估值底}

东方财富一致预期（图表8-1第6列）是全市场最保守的一层估值。以12只有完整区间数据的标的测算，一致预期对应的2026E PE多在10--25x区间，反映的是传统PCB/CCL行业的周期估值框架，主要锚定历史盈利中枢和行业周期波动。

这一层估值的特点是：（1）\textbf{AI溢价反映慢}——多数券商盈利预测仍以传统业务为主，AI相关的高端产品ASP提升、客户导入和产能爬坡尚未充分计入EPS模型；（2）\textbf{机构口径混杂}——覆盖机构从5家到29家不等，小样本标的统计收敛性差，且可能包含非AI链研究机构的保守预测；（3）\textbf{更新滞后}——公开聚合数据随研报发布低频更新，通常滞后于市场情绪1--2个月。

这一层估值的意义在于提供了\textbf{估值底部锚点}：如果股价跌到一致预期区间内，说明AI主题溢价基本退潮，回到了传统行业估值水平，安全边际较高。

\subsection{第二层：本报告合理价值区间——已验证证据的定价}

本报告合理价值区间（图表8-1第5列）处于三层估值的中间位置。我们在传统估值框架基础上，\textbf{仅计入已验证的AI相关证据}：已量产的高端产品、已认证的客户、已交付的订单、已爬坡的产能。对应PE带通常为30--60x 2026E，显著高于行业历史中位，但低于最激进的科技股估值。

与一致预期相比，我们的估值溢价来自三个已验证的结构性变化：

\begin{enumerate}
\item \textbf{产品结构升级已兑现}——沪电/深南的AI服务器PCB、生益的M8/M9高速CCL、胜宏的HDI高阶板，均已进入量产或小批量阶段，ASP和毛利率的提升是已发生的事实，不是预测；
\item \textbf{国产替代空间已打开}——南亚新材高速覆铜板、芯碁微装直写光刻设备、大族数控钻孔设备，均已在头部客户实现突破，国产替代的市场空间是可量化的，不是纯叙事；
\item \textbf{盈利质量已改善}——核心标的2026Q1收入和利润同步高增长，毛利率由高端产品结构驱动而非一次性因素，盈利的可持续性优于上一轮周期。
\end{enumerate}

我们与一致预期的核心方法论差异是：\textbf{一致预期按"传统PCB公司"估值，我们按"AI硬件链公司"估值，但仅计入已验证的部分}。这就是为什么本报告估值普遍高于东方财富一致预期10--50\%——不是我们更乐观，而是我们认为AI对盈利结构的改变已经发生，不应再用纯周期框架定价。

但同时我们也拒绝计入未兑现的叙事期权：尚未导入的客户、尚未量产的产品、尚未验证的ASP提升，都不进入估值模型。这也是为什么本报告估值显著低于最激进的外资投行目标价。

\subsection{第三层：外资投行具名目标价——叙事溢价的顶部}

外资投行具名目标价（操作建议列【外资】标签）是三层估值中最激进的一层。以生益科技为例，东方财富一致预期83--104元，本报告150--205元，高盛目标价217.6元、花旗195元，外资目标价较一致预期溢价超100\%。

外资目标价如此激进的原因：（1）\textbf{全球科技股估值框架}——外资行将PCB/CCL龙头纳入全球AI硬件供应链估值体系，给予与半导体设备、光模块类似的成长股估值倍数（45--60x 2027E PE），而不是传统制造业估值；（2）\textbf{远期盈利外推}——普遍将2027--2028年的高速增长外推，并假设ASP和毛利率持续提升；（3）\textbf{全球配置视角}——中国PCB/CCL公司在全球供应链中的份额提升逻辑，叠加人民币资产重估，构成额外溢价。

这一层估值的风险也最大：如果Q2--Q3的盈利兑现不及预期，或者AI capex出现放缓信号，外资目标价面临快速下修风险。投资者若以这一层估值作为买入依据，需要同时承担盈利验证风险和估值收缩风险。

\subsection{三层估值的使用建议}

不同风险偏好的投资者应选择不同的估值锚：

\begin{itemize}
\item \textbf{保守型投资者}：以东方财富一致预期为锚，股价回落至一致预期区间上沿以下时再考虑配置，安全边际最高但可能错过行情；
\item \textbf{稳健型投资者}：以本报告合理价值区间为锚，在区间中下部布局，承担"已验证部分"的估值风险，同时享受盈利兑现带来的估值上移空间；
\item \textbf{进攻型投资者}：可以参考外资目标价作为上行空间的参考，但必须以订单、毛利、客户验证等触发器严格约束仓位，一旦证伪立即止损。
\end{itemize}

无论使用哪一层估值，核心纪律都是\textbf{估值必须绑定证据}。估值可以乐观，但乐观的每一块钱都要能找到对应的证据支撑。证据增加，估值中枢上移；证据不足，估值中枢下移。这是本报告始终坚持的原则。

\paragraph{House-view收束：哪个变量最威胁核心标的目标PE带}

回扣全章三约束（Q2节奏、毛利率驱动、客户链证据），本报告的估值中枢可被一句话概括：核心四家中，威胁最大的是\textbf{CCL材料价格/组合这一单一变量}，且威胁集中压在生益科技一家。

理由有三。其一，图表8-14组合压力列里生益EPS下行-13.8\%为核心4家最大，且来源单一——CCL涨价与组合升级同向暴露，没有第二个缓冲变量。其二，图表8-3反向估值里生益当前市值隐含净利门槛（71.9--95.9亿）已逼近2027E基准预测（78.6亿）的上半区，是核心四家中安全水位最薄者。其三，图表8-8一年分位里生益PE/PB双双100\%，意味着任何CCL反转都会触发EPS与估值倍数同步下修的双杀。三套独立证据指向同一变量、同一标的。

\textbf{若该变量下行情景兑现，估值应如下修订。} 对生益：目标PE带从45--60x 2027E下调至35--45x 2027E（放弃材料景气期溢价、回到常态材料估值），对应合理价值区间从150--205元下修至约115--150元，评级由"核心跟踪/估值拥挤"转为"验证为先、严控仓位"，以M8/M9价格或交期任一出现季度环比反转作为降仓位触发器。对沪电和深南：CCL并非其核心变量，下行时目标PE带可分别从45--55x下调至40--50x，对应合理价值区间下沿下移约10\%--15\%，但仍维持核心跟踪——它们的估值容错率足以吸收单一变量温和下行。对胜宏：威胁来自客户集中度而非CCL，若ASIC客户放量低于开源预测的2027E净利154.41亿元基准，目标PE带从30--38x收窄至28--32x，对应股价区间下沿从290元下修至约270元，但仍留在进攻观察而非剔除——弹性窗口未关闭。

这一收束是全章的逻辑闭环：开篇提出的三约束，在敏感性框架里被分别量化为生益的CCL阈值、深南的载板良率阈值和沪电的订单节奏阈值，每个阈值都对应明确的目标PE带下修幅度和评级调整动作。读者据此可以判断——任何一个约束被证伪时，本报告的估值中枢应当如何机械地而非情绪化地调整。

\section{扩充标的估值方法说明}

图表8-1中Core Candidate、Watchlist和设备耗材共16家标的的合理价值区间，证据强度低于核心6家，需单独说明推导方法和局限性。

扩充标的的参考价值区间按四类方法分层，均为公开数据或定性判断的结构化呈现，\textbf{不构成可精确量化的目标PE带}：（1）\textbf{行业可比公司PE均值}——选取同环节PCB/材料/设备公司的估值带作为基准，再根据标的自身卡位溢价或折价调整；（2）\textbf{历史估值分位}——参考近1年/3年PE/PB分位判断当前水位高低；（3）\textbf{卖方一致预期PE}——引用东方财富等公开聚合的机构一致预期数据（样本量差异较大，芯碁/大族等9--16家，景旺6家、南亚5家，东山/宏和/巨石等缺失）；（4）\textbf{定性判断折扣/溢价}——对PE失效、伪AI概念、A/H不可比、需求侧锚等特殊情形采用定性风险提示，不适用PE倍数定价。四类方法的选取由各标的的证据边界决定：证据越充分，越偏向行业可比与一致预期；证据越薄弱，越偏向定性判断与风险提示。

以下按类别逐一说明19家非核心标的的估值推导依据和风险提示：

\textbf{Core Candidate 3家（可投资但需更宽区间）}——芯碁微装参考半导体设备行业PE（北方华创/中微公司等估值带），打技术成熟度折扣，结合16家卖方一致预期EPS 3.94元推导；东山精密参考PCB行业可比PE均值 + 光模块/光芯片一体化溢价（参考中际旭创链估值水位），打整合风险折扣，因Google ASIC链未获filing确认，溢价部分由needs-IR假设支撑；景旺电子参考二线PCB厂商PE均值 + 1.6T光模块PCB卡位溢价（低于一线龙头沪电/深南），结合6家卖方一致预期EPS 2.03元（2026E）与目标价75.43元校准，因2026Q1归母-28\%与PE约69x存在张力，需等中报修复剪刀差，现价较一致预期目标价溢价约7\%。

\textbf{上游材料Watchlist 9家（PE弹性大，证据密度不一）}——南亚新材参考高速覆铜板国产替代标的PE，结合5家卖方一致预期EPS 2.35元推导，M6量产、M8送样为核心卡位；宏和科技参考电子玻纤布行业PE + Low-Dk高端布叙事溢价，但因TTM PE约750x属叙事溢价极值、公司主动提示扩产不确定，给大幅折价；东材科技参考特种树脂行业PE + AI高速树脂国产替代溢价，但扣非+42\%远弱于表观+103\%、董事长减持，给折价；铜冠铜箔参考铜箔材料行业PE + HVLP5/载体铜箔故事期溢价，但毛利率仅8.79\%、OCF为负、HVLP5未量产，给大幅折价；宏昌电子PE$>$4,000x实质失效，改用PB估值法（行业常态2--3x）对应约6--9元作为价值回归方向参考；中材科技参考玻纤行业PE + AI电子布概念溢价，但AI电子布收入占比仅2.08\%、OCF与净利严重背离，给大幅折价；中国巨石参考玻纤周期PE，不享受AI成长溢价（公司已澄清AI收入占比0\%），仅作周期景气锚；金安国纪参考普通CCL行业PE，扣除AI概念溢价后（公司两次澄清未进入NVIDIA/华为链、未做高速M6/M9），仅作风险反例参照；容大感光参考PCB光刻胶/耗材行业PE + 国产替代叙事溢价，但2026Q1归母-22\%、OCF为负、监管函为治理风险点，给折价。

\textbf{设备与耗材4家（扩产周期受益，估值分化大）}——大族数控参考PCB设备行业PE，结合9家卖方一致预期EPS 3.31元推导，钻孔设备龙头直接受益PCB厂扩产，但现价高于目标价；鼎泰高科参考精密刀具/耗材行业PE，结合8家卖方一致预期EPS 2.51元推导，需验证高端刀具国产替代进度；兴森科技参考FCBGA封装基板标的估值，因PE 563x基数扭曲意义有限，重点看FCBGA爬坡进度；劲拓股份参考PCBA装联设备行业估值，链条相关度低于PCB设备/材料，缺乏明确AI敞口证据，仅作产业链边际观察。

\textbf{需求指标与港股锚3家（不纳入目标价体系）}——中际旭创为1.6T光模块全球龙头，是"光--PCB"传导链需求端先行指标，不进入PCB组合；工业富联为AI服务器+高速交换机需求侧锚，验证AI capex是否真实落地；建滔积层板为港股CCL全球龙头、AH定价锚，2025H2--26累计涨价$>$50\%构成高端CCL景气外生确认信号，A/H口径不可比，仅作全球量价风向标。

以上19家非核心标的的参考价值区间，均为基于公开信息的方向性判断，证据强度显著低于核心6家。投资者使用时应牢记：核心6家的目标价是"可以据此配置"的级别，Core Candidate是"可以轻仓试错"的级别，Watchlist和设备耗材是"仅作跟踪观察"的级别，需求锚和港股锚是"只用来验证逻辑、不直接投"的级别。任何扩充标的若要升级为核心估值目标，必须先满足两条门槛：其一，建立可编辑经营线模型（收入、成本、费用、净利、现金流、资本开支完整链条）；其二，取得客户/平台自下而上EPS证据（具名客户收入、平台单价、产能利用率、项目级经济性）。
