风险传导按标的分组如下：
\begin{itemize}
  \item AI资本开支或订单节奏放缓 → 优先影响胜宏、鹏鼎等高弹性客户链标的 → 高弹性PCB从核心/进攻降为观察。
  \item M8/M9价格和交期反转 → 优先影响生益、南亚、华正等材料链 → 重新评估CCL价格传导与毛利支撑。
  \item 产能过剩迹象出现 → 设备耗材和高CAPEX公司需要更严格的折旧和现金流压力测试 → 下调情景倍数，要求订单验证。
\end{itemize}

\section{失效条件 / Invalidation}

以下任一情况出现，需重估目标估值与标的分组：

\textit{阈值的性质与校准依据：}下述阈值\textbf{为分析判断阈值，而非历史波动或同业基准校准}——本案例数据/分析底稿中未保留核心标的（胜宏/沪电/生益/南亚）连续8--12季的TTM毛利率波动区间与OCF/净利润比值序列，因此无法证明“3个百分点”“0.7”“10\%”落在历史波动带边缘。各阈值按风险侧别设定：需求侧（连续两个季度低于预期）取经验观察窗口；“3个百分点毛利率回落”与“OCF/净利润比值低于0.7”属盈利质量侧的分析假设，分别对应毛利趋势反转与利润含金量恶化的经验阈值；“10\%在手订单环比负增长”属订单可见度侧的分析假设。读者应将其视为定性失效线的\textbf{量化锚定}，而非精确统计校准。

\begin{riskbox}[失效条件]
若出现以下任一情况，本报告的核心跟踪框架需要下修或重做：
\begin{itemize}
  \item AI服务器、ASIC或高速交换机资本开支连续两个季度低于预期，同时核心公司订单/产能利用率转弱。
  \item M8/M9等高端CCL涨价和交期紧张逆转，且材料厂毛利率较TTM高点回落超过3个百分点。
  \item 核心标的在收入高增的同时经营现金流/净利润比值低于0.7连续两个季度，或毛利率较TTM高点回落超过3个百分点，或在手订单环比负增长超过10\%，说明需求兑现质量不足。
  \item 玻璃基板、CPO或其它互联架构实质性转移PCB/CCL价值池，导致本报告的价值链映射失效。
  \item 官方披露或可信原始报告否定当前平台链代理关系或关键技术路线。
\end{itemize}
\end{riskbox}
