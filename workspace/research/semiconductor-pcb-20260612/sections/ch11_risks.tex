\section{风险热力图}

风险章节的作用是定义"什么会让本报告错"。对半导体PCB链条而言，最大的风险不是某个单季度波动，而是AI资本开支节奏、技术路线、材料价格和产能周期同时改变盈利曲线。风险必须落到触发条件和投资动作，否则只是免责声明。我们按概率——影响两维把七项核心风险定位在热力图上，高概率高影响项是组合调整的优先触发器，低概率高影响项是尾部风险对冲的观察对象。

风险热力图的投资含义分三层。第一，高概率高影响的AI资本开支放缓是核心风控锚——一旦触发，所有高弹性标的的情景倍数都需要下修，而非仅调整个别标的。第二，中高影响的技术路线迁移、客户集中度和地缘政治属于"低频高损"风险，不应作为基准假设，但必须在单一标的上留有安全边际。第三，估值拥挤和产能过剩是周期属性风险，决定入场时点而非长期逻辑——价格消化估值后，核心看多逻辑仍然成立。

\section{监控清单与工作流}

监控清单用于把风险管理变成后续工作流。月度跟踪平台节奏和材料价格，季度跟踪收入、毛利、现金流和折旧，事件驱动跟踪技术替代和客户认证变化。每一次更新都应该回答：原来的投资假设是增强、削弱，还是失效。监控不是记录数据，而是触发动作——信号越过阈值即执行对应调仓，而非等待季报确认。

\section{失效与恢复条件 / Invalidation \& Recovery}

以下条件定义了本报告核心框架的失效边界和重新纳入标准。失效条件回答"什么时候我们错了"，恢复条件回答"什么时候可以重新看多"——两者对称，构成完整的风险闭环。

\textit{阈值的性质与校准依据：}下述阈值\textbf{为分析判断阈值，而非历史波动或同业基准校准}——本案例数据/分析底稿中未保留核心标的（胜宏/沪电/生益/南亚）连续8--12季的TTM毛利率波动区间与OCF/净利润比值序列，因此无法证明"3个百分点""0.7""10\%"落在历史波动带边缘。各阈值按风险侧别设定：需求侧（连续两个季度低于预期）取经验观察窗口；"3个百分点毛利率回落"与"OCF/净利润比值低于0.7"属盈利质量侧的分析假设，分别对应毛利趋势反转与利润含金量恶化的经验阈值；"10\%在手订单环比负增长"属订单可见度侧的分析假设。读者应将其视为定性失效线的\textbf{量化锚定}，而非精确统计校准。

\begin{riskbox}[失效条件]
若出现以下任一情况，本报告的核心跟踪框架需要下修或重做：
\begin{itemize}
  \item AI服务器、ASIC或高速交换机资本开支连续两个季度低于预期，同时核心公司订单/产能利用率转弱。
  \item M8/M9等高端CCL涨价和交期紧张逆转，且材料厂毛利率较TTM高点回落超过3个百分点。
  \item 核心标的在收入高增的同时经营现金流/净利润比值低于0.7连续两个季度，或毛利率较TTM高点回落超过3个百分点，或在手订单环比负增长超过10\%，说明需求兑现质量不足。
  \item 玻璃基板、CPO或其它互联架构实质性转移PCB/CCL价值池，导致本报告的价值链映射失效。
  \item 官方披露或可信原始报告否定当前平台链代理关系或关键技术路线。
\end{itemize}
\end{riskbox}

\begin{keyinsight}[恢复条件 / Re-entry Criteria]
若已触发失效、后续出现以下任一情况，可重新上修框架或恢复标的跟踪：
\begin{itemize}
  \item AI服务器、ASIC或高速交换机资本开支重回增长轨道，连续一个季度环比改善且核心公司在手订单恢复正增长。
  \item M8/M9等高端CCL价格止跌企稳，交期恢复延长，且材料厂毛利率连续两个季度环比回升。
  \item 核心标的经营现金流/净利润比值回升至0.8以上，且毛利率连续两个季度环比改善，或在手订单环比转正并持续两个季度。
  \item 新技术路线经验证后PCB/CCL价值量影响低于预期，或公司成功切入新技术供应链并贡献可观收入。
  \item 官方披露或可信原始报告确认平台链代理关系或关键技术路线，证据等级提升。
\end{itemize}
\end{keyinsight}
