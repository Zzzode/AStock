\section{持仓分层与执行框架}

投资操作指引的重点不是给出一个静态买入清单，而是把研究结论转成可执行的后续动作。半导体PCB链条目前处在"高景气已被市场交易、业绩验证还在继续"的阶段，因此更适合用触发器框架：核心跟踪组等待业绩质量确认后决定加减仓，进攻观察组等待证据增强或估值回落，主题储备组等待官方财务和订单证据，观察名单与候选资产则按证据质量逐级推进。

\begin{keyinsight}[核心操作结论]
当前不是全行业加仓时点。核心跟踪组（沪电、深南、生益）维持重点复核，仓位随Q2/中报收入、毛利率、现金流同步验证的质量动态调整；进攻观察组（胜宏、华正）在客户链证据增强或估值回落时上修权重；Core Candidate待EPS桥建立后进入正式评级；Watchlist保留产业跟踪，不进入推荐序列；需求指标与港股锚仅作验证参考，不作为A股持仓标的。
\end{keyinsight}

持仓分层按交付确定性、客户链证据强度、估值安全边际和近催化四个维度划分，与第八章评级体系完全对齐。分层的目的不是给股票贴标签，而是明确每一层的进入和退出条件，避免因叙事热度随意跨层调仓。

执行层面，仓位与目标估值均由触发条件驱动，不复述分组逻辑。核心跟踪并非马上加仓，仓位应随业绩质量动态调整——若Q2收入、毛利率和现金流同步兑现，维持核心权重；若只有收入增长而利润质量走弱（现金流或毛利率恶化），应将对应公司目标估值中枢整体下修。进攻观察组的机会来自预期差，触发加仓需客户链或订单证据配合，否则高估值会放大回撤；主题储备组在官方财务与订单证据到位前不进入核心权重。Core Candidate在EPS桥建立前不给出目标价，Watchlist则完全不进入组合讨论。

时间线上，节点1为现状基线（行情快照与估值拥挤确认），首个决策性验证点是节点2的中报。如果中报验证毛利率和现金流，估值可以继续承受较高倍数；如果中报只验证收入不验证利润，后续Rubin/ASIC叙事也难以完全支撑当前估值。节点3--5是中期变量：Rubin/ASIC平台放量需配合客户链证据才上修进攻观察组与Core Candidate权重；M8/M9 CCL价格与交期直接驱动生益/华正的估值中枢（呼应图表8-3的M8/M9回落下修条件）；节点5的CAPEX投产后利用率与折旧对应产能爬坡组的折旧压力测试，触发则下调情景倍数。节点6的年度业绩复核是最终检验窗口，决定核心跟踪组是否维持高景气溢价。

不同分层的关键催化窗口不同：核心跟踪组的决策窗口在节点2（中报）和节点4（材料价格）；进攻观察组的关键窗口在节点3（客户平台）和节点5（产能爬坡）；Core Candidate和Watchlist的升级窗口分布在全部节点，任何一个节点出现超预期证据都可能推动分层上移。

\section{后续证据优先级}

下一轮研究要优先补三类证据：第一，分业务收入和毛利率，用来判断AI订单是否真正高附加值；第二，客户链和平台节奏，用来判断增长是否可持续；第三，产能爬坡和现金流，用来判断扩产是增厚还是摊薄EPS。没有这些证据，任何目标价都只能是宽区间。

需特别说明可行性边界：分业务收入受A股年报披露口径限制，部分平台/客户层级只能通过IR交流纪要（互动易、路演）补充而非公开财务报表直接获得；具名客户收入拆分、M8/M9/M10代际收入与毛利、平台收入拆分属于本轮公开来源可能永远无法补齐的硬缺口，与本报告\texttt{completion\_audit\_manifest}的\texttt{do\_not\_mark\_complete}边界一致，不应作为可补齐证据呈现。

\textbf{证据优先级（按对评级影响的边际大小排序）}：公司交付（分业务收入/毛利率）> 客户链放量 > 产能爬坡现金流 > 材料价格ASP > 来源质量。最高优先级触发器是下一份中报能否给出分业务毛利率——这决定核心跟踪组权重是否维持；客户链放量决定进攻观察组和Core Candidate是否上修；其余三类为支撑性证据，单独补齐不直接改变评级。

证据升级有明确门槛：仅补到券商摘要、转载或OCR线索，不构成证据升级，结论强度不上调——这与本章对鹏鼎"主题储备"的处理一致。能真正改变评级的证据，必须直接改变收入、毛利率、订单可见度或现金流假设，而非仅新增一条叙事或一致预期。公司公告、IR记录和原始完整模型表，是上调强度的最低证据门槛。

分层升级的具体触发条件如下：
\begin{itemize}
\item Watchlist $\rightarrow$ Core Candidate：AI相关收入进入年报分部（>5\%）或核心客户认证取得官方确认；
\item Core Candidate $\rightarrow$ 主题储备：建立完整EPS桥与估值锚，且客户链证据交叉验证通过；
\item 主题储备 $\rightarrow$ 进攻观察：官方财报确认AI相关收入与毛利贡献，订单可见度延伸至下一年度；
\item 进攻观察 $\rightarrow$ 核心跟踪：连续两个季度验证收入、毛利率和现金流同步增长，估值回到安全区间。
\end{itemize}
