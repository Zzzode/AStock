## Raw Interface Probe Notes

- P5W static HTML pages are Vue shells; the visible question and reply body can be absent from the HTML even when the page URL is valid.
- `interaction/getQaByQid.shtml` returned full JSON for Shennan question `0001FB6C969FE01C4328A5F8BFA921BD83C8`.
- `interaction/getNewR.shtml` keyword search returned useful AI-topic rows for Shennan, but Rubin/confidentiality keyword probes were inconsistent. Those failed probes are archived and should not be promoted into main evidence.
- For Hudian, P5W question-list HTML was archived as `data/raw_hudian_p5w_questionlist.html`, and P5W keyword probes for Rubin / Google / commercial policy returned empty rows. CNInfo/SZSE company-question endpoints later recovered primary JSON rows for Rubin, Google, NVIDIA/AMD/cloud ratio, LPU/LPX and domestic compute customer questions.

## Conclusion

The remaining named-customer revenue split gap is not just missing analyst work. Public company responses indicate that specific customer names and business details are restricted by commercial confidentiality. Hudian, Shenghong and Shennan now have primary CNInfo/P5W/SZSE interface evidence for this boundary. This supports keeping named NVIDIA / Google / ASIC / domestic compute customer claims in the rumor registry unless an original, attributable source is obtained.
