# Template Brief — 雅化集团完整单票覆盖

- **原型：** JPM 单票研究首页的“行动—目标价—盈利表—价格表现”布局，加上周期材料公司必须具备的单位经济、现金转换与情景估值章节。
- **读者：** 投资组合经理，而非研究流程审计人。首页应在一页内回答：现在做什么、为何现在、基准目标、熊/牛回报、下一次触发器和什么会让观点失效。
- **报告定位：** 中低信心的业绩验证型完整覆盖。正式 H1 尚未披露是预测置信度的折扣因子，不是正文的主题。

## 章节与展品合同

1. **IC 摘要：** 当前价、目标、评级、三情景、风险预算、催化剂、H1 验证点。
2. **预期差：** H1 预告与外部预测、市场已计入的 H2 门槛、我们的不同假设和最强反方。
3. **锂盐盈利引擎：** 历史销量/收入/吨收入、2026--2027 量价成本桥和主要敏感性。
4. **民爆与现金防线：** 产品、矿服、运输的收入毛利、季节性、回款和下行保护。
5. **财务质量：** 季度盈利、经营现金流、应收、存货、资本开支与债务。
6. **竞争、资源与客户：** 已验证的关系、零信用字段、同行相对位置。
7. **估值与交易位置：** 周期校准 PE / 分部交叉检查、同行、卖方、多锚、技术与流动性。
8. **催化剂与风险：** 事件日历、量化阈值、概率—影响矩阵和行动纪律。

## 形式规则

- 每章首段先讲因果结论，展品后必须解释对盈利、估值或行动的影响。
- 读者正文只出现可读的来源名称和日期；内部文件路径、门禁、重做过程只保留在审计材料。
- 至少使用盈利桥、情景表、敏感性表、同行 scorecard、时间线和风险矩阵六种不同展品；不以连续表格充页。
- 对资源、客户、订单和自供比例，明确标示“已证实 / 仅公司表述 / 未披露”，并将未披露项从基准估值中剔除。
