# 雅化集团重建规格：从“证据清单”回到“可决策单票研报”（历史完整覆盖规格）

> **当前处置：** 本规格记录签发完整单票覆盖所需的后续条件。截至 2026-07-23，正式 H1 三表和公司层面的 H2 单位经济桥均未披露；当前交付因此为 `earnings_preview_event_research`。正式 H1 后必须重新启动本规格，不能把事件研究直接改名升级。

## 结论

当前 PDF 不是一份可签发的 `single_stock_full_note`，而是一份“为什么暂不建模”的证据边界说明。它诚实地列出了缺口，但没有回答投资委员会真正需要回答的问题：**在 16.79 元的价格上，市场已经计入什么；2026--2027 年每股盈利由哪些可验证变量决定；我们的判断与卖方、市场之间的差异是什么；在什么价格、什么证据和什么时间点应该买入、加仓、降低仓位或放弃。**

这不是措辞问题，而是报告产品与其自称类型不一致：`research_brief.md` 和 `template_brief.md` 已要求“全年盈利桥、三情景 SOTP、当前价/目标价/上行、行动标签”，但正文和 `valuation_model.md` 把所有这些内容替换成“当前价复述”。因此，现有“观察名单”结论不是一个信息充分的投资结论，也不能被 `Model Reproducibility: PASS` 或“94 分”掩盖。

本规格要求重建一份**有条件但有立场**的单票报告：所有事实、假设、外部预测与我们的判断分层；证据不足的变量以区间、情景权重和明确的降级条件表达，而不是将整份报告退化为“不说”。若重建时确实无法得到最低模型证据，应停止冒充完整覆盖，改交付为“半年报前业绩预告事件研究”，并明确其不能替代全覆盖目标价报告。

## 单票报告必须回答的八个判断问题

以下问题必须在第一章摘要中先给结论，在后续章节给量化证据。每一题都需要“我们的判断 / 反方判断 / 下一份证据 / 对 EPS 和估值的影响”。

1. **2026H1 利润预告的质量是什么？**
   - 区分归母与扣非、经营性与可能的一次性项目、收入增长、毛利变化、费用、所得税和现金转换。
   - 不能只写“同比改善”；要回答 H1 的 11.0--13.0 亿元利润相对各卖方 H1 假设、2026 全年预测和 2025 年基数意味着什么。

2. **锂盐业务的利润修复能否延续到 H2 和 2027？**
   - 拆为销量、实现售价、锂精矿/加工成本、库存、客户结构和产能利用率；给出 H2 的熊/基准/牛情景。
   - “锂价上涨”“客户名单”“设计产能”不能单独构成答案。

3. **民爆究竟是下行保护还是只是收入标签？**
   - 给出产品、爆破服务、运输的收入、毛利、固定费用/项目回款与现金转换的历史和前瞻桥。
   - 必须说明在锂盐熊市中民爆能覆盖多少费用、贡献多少 EPS 下限，而不是泛称稳定器。

4. **资源安排是否改变吨成本与盈利波动？**
   - 李家沟权益、优先供应、KMC 安排必须连接到实际供应量、权益口径、交付节奏、回收率和单位成本；无法证明时明确为零成本优势信用。

5. **公司相对赣锋、天齐、永兴等可比公司的差异在哪里？**
   - 用资源自给、产品形态、销量、成本曲线、客户/区域、民爆业务、现金流和估值倍数回答，而不是只列公司名称。

6. **当前价格已经计入了什么？**
   - 在 2026-07-22 的 16.79 元、193.52 亿元市值上，计算对自有熊/基准/牛 EPS 的 PE，对卖方 EPS 范围的交叉核验，以及相对可比的溢折价。
   - 说明低倍数是盈利上修机会、周期顶部风险、现金流折价，还是三者组合；不能把“6--8 倍”本身当作便宜结论。

7. **我们的预期差是什么？**
   - 卖方共同观点、市场可能交易的核心变量、我们不同的变量/概率/时间点、最强反方理由和证伪条件必须写清。
   - 若没有可验证的不同判断，报告不能自称完整覆盖，只能是资料整理或事件跟踪。

8. **现在应如何行动？**
   - 给出明确的 `买入 / 增持 / 持有 / 减持 / 回避 / 事件型观察` 之一，适用期限、目标或公平价值区间、预期上行/下行、概率加权结果、仓位纪律和催化剂日历。
   - “观察名单”只有在其被定义为一个事件型行动（进入条件、退出条件、复核日期、不可交易原因）时才成立；它不能替代第 1--7 题。

## 最低可接受证据与模型合同

### 1. 财务与现金流：必须先完成

| 模块 | 最低证据 | 可接受代理 | 不可接受替代 | 输出 |
|---|---|---|---|---|
| 2026H1 质量 | 正式 H1 报告的三张表、利润表附注、库存与营运资本变化 | 若正式 H1 尚未披露，仅可作“预告事件研究”，不能签发全年目标价 | 只用 H1 归母预告区间 | H1 实际 vs 预告 vs 卖方的差异桥 |
| 锂盐收入 | H1 销量和实现售价，或公司可复核收入/销量数据 | 完整卖方原始模型的数量/价格假设可作二级交叉验证，且须标注来源 | 用设计产能、客户名单或行业现货价替代销量 | 2025A--2027E 销量 × 实现单价桥 |
| 锂盐成本/利润 | 原料来源、精矿/加工成本或分部毛利/利润披露 | 保守区间加敏感性；采用时说明每吨变动对 EPS 的传导 | 直接把锂盐价格变动乘总收入或合并利润 | 单吨收入、单吨现金成本、吨利润、毛利至净利桥 |
| 民爆基准 | 产品/服务收入、毛利、项目进度、应收/经营现金流和许可利用率 | 对未披露 2026 项目采用明确的持平或保守同比假设 | 把 2025 民爆收入全部等同为稳定净利 | 民爆收入--毛利--费用--净利/现金流桥 |
| 合并到 EPS | 税率、少数股东、财务费用、股本/摊薄股数 | 历史可观察比率，列为假设并做敏感性 | 以合并归母利润直接倒推任何分部价值 | 分部 EBIT/净利到归母净利到 EPS 的可复算表 |

### 2. 行业、资源与需求：必须回答“为什么能/不能持续”

1. 建立有日期、来源与单位的碳酸锂/氢氧化锂月度价格序列；分别展示 H1 实际、当前点位、H2 与 2027 的熊/基准/牛假设。
2. 给出电池、储能和主要区域需求的可追溯量化指标；需求不能只写宏观口号，必须连接到雅化产品、客户和确认收入的时间滞后。
3. 对矿端供给、李家沟、KMC、长协与外购，列明“已供/可供/设计/权益/成本”五个不同口径；未取得实际供给和吨成本时不得把资源写成成本优势。
4. 量化民爆行业的许可产能、利用率、地区项目机会、产品与服务毛利差、回款周期；政策只可解释方向，不能替代订单。
5. 选取至少三家业务可比公司，形成统一的资源、锂盐销量、成本/毛利、民爆或其他缓冲业务、现金流、估值和 2026--2027E 增长比较。

### 3. 预期差、市场与估值：必须形成一个可执行答案

1. **卖方复盘：** 从三份完整 PDF 提取每家分析师的 2026/2027E 收入、净利、EPS、锂盐量价/成本假设、民爆假设、目标价和估值方法；将 H1 预告或正式 H1 结果逐项与这些假设对比。
2. **自有模型：** 不是“平均三份券商预测”。必须独立选择并说明销量、实现价格、成本、民爆基准、费用、税率、股本和情景概率；券商预测只能用作合理性区间检查。
3. **估值：** 采用与业务相符的两种独立方法，至少包括“分部/周期归一化 PE 或 SOTP”和“可比公司相对估值”。若使用 PB、EV/EBITDA，须说明为何比 PE/SOTP 更合适。不能拿同一个 EPS 乘两个倍数伪装为两种方法。
4. **三情景：** 每一档都必须有销量、ASP、成本、民爆假设、归母净利、EPS、倍数、价格、概率、现价上行/下行和触发条件。概率合计 100%，并能从结构化 JSON 复算。
5. **当前价格：** 使用统一的价格日期、总股本与市值；将当前 PE、PB、EV/EBITDA 与历史/可比区间比较，解释折溢价来源。技术面只作为交易拥挤度和入场节奏，不作为基本面估值锚。

### 4. 证据分层纪律

- 一级：公司正式披露、交易所公告、审计报表、官方行业统计；用于事实和核心模型输入。
- 二级：可追溯的完整券商 PDF、可信的商品价格/行业数据库；可用于交叉验证、情景和可比估值，不能无标注变成公司指引。
- 三级：媒体、摘要、搜索结果；只作线索，不进入数字模型。
- 每一项模型输入都要有 `source_id`、日期、口径、直接性、适用情景、对 EPS 的敏感性和失效条件。没有来源的假设必须在模型中以高/中/低置信度与区间显式呈现，而不是藏在正文。

## 明确禁止的伪门禁做法

1. **不得把当前价格写为目标价。** `final_target=current_price`、三情景同价和 `upside=0%` 不是中性估值；它只能表示没有模型，不能让估值门禁通过。
2. **不得在没有盈利模型时写 `Model Reproducibility: PASS`。** 可以复算市值不等于可以复算公平价值、评级或收益预期。
3. **不得以“全部权重为零”代替估值。** 基本面、市场和券商权重全部为零时，报告不具备单票完整覆盖的估值结论。
4. **不得把“资料不足”写成整份报告的主体。** 证据缺口必须转化为变量、概率、情景、下一次可验证事件和对价格的影响。
5. **不得把外部券商 EPS 平铺成“市场共识”。** 需标明报告日期、原始 PDF、假设差异、分歧来源和 H1 验证结果；一份 42 元目标价绝不等于一致预期。
6. **不得把 H1 合并利润年化，也不得把行业现货价、设计产能、客户名称或资源权益直接转为 EPS。** 每一步都要经过数量、实现价格、成本、分部利润、税费和股本。
7. **不得将研究工作流语言写进读者正文。** “本次重做”“保留/删除”“门禁”“接口字段”等只属于内部审计记录。
8. **不得让模板、JSON 或验证脚本定义研究结论。** 先完成投资判断和模型，再以脚本检查一致性；不能为了通过字段检查制造伪数值。
9. **不得在 R4 标记 PASS，除非报告真的有可决策的价格结论或被明确改类为非投资性事件研究。** “观察名单”不是对完整单票报告的自动豁免。

## 交付路径：完整覆盖与诚实降级二选一

### 路径 A：重新签发 `single_stock_full_note`

仅当以下条件全部满足时使用：

1. 已取得正式 H1 三张表或等效的可审计利润、收入、现金流和营运资本资料；
2. 锂盐和民爆至少各有一条从经营变量到利润的可复算桥；
3. 自有熊/基准/牛 2026E--2027E EPS 模型已建成，且与 H1、卖方、可比和商品价格进行交叉验证；
4. 当前价、可比估值、两种估值方法、目标/公平价值区间、上/下行、概率和评级均在 PDF 与结构化模型中一致；
5. R0--R4 的每项结论都审查“模型是否有判断”，而不是“文件是否存在”。

应交付的结论形式示例：`增持 / 基准情景公平价值 xx 元 / xx% 上行 / 12 个月 / 仓位上限 xx%`。数值必须由实际重建模型产生，不预设在本规格中。

### 路径 B：改类为“半年报前业绩预告事件研究”

若 H1 正式三表、分部单位经济或可信的 H2 桥仍不可得，必须停止称其为“完整研报”，改交付以下更诚实、但仍有信息增量的产品：

**《雅化集团：H1 业绩预告事件研究——利润预告相对卖方预期、现金流验证与正式半年报交易条件》**。

它必须包含：

1. H1 预告低/中/高端相对每家卖方 H1、2026E 与 H2 隐含利润的差异；
2. 16.79 元对应卖方 EPS 范围的 6.38--8.35 倍交叉核验，并明确这不是自有目标价；
3. 正式 H1 报告的三类可交易结果：利润/收入/现金流同时验证、利润验证但现金转换差、利润低于预告；每类对应的行动、需重建的 EPS 区间和取消条件；
4. 锂盐价格、库存、应收、经营现金流、民爆项目回款的事件日历和可观测阈值；
5. 明确的报告有效期（至正式 H1 披露后复核），且不写“完整覆盖”“目标价”“买入评级”。

这条路径不是“什么都不说”：它对**业绩事件与验证路径**给出完整判断；只是不会伪装成已经拥有全年基本面模型的投资建议。

## R0--R4 重新验收标准

| 周期 | 不可缺少的判定 | 拒绝签发条件 |
|---|---|---|
| R0 证据 | 每个高影响模型变量有来源、口径、日期、直接性和失效边界；H1 正式资料/事件研究边界已确定 | 把未披露字段当事实，或无来源假设进入 EPS |
| R1 模型 | 独立 H2 和全年盈利桥，分部到 EPS 可复算；两种估值方法与三情景可复算 | 只有当前价、市值或券商预测，没有自有盈利桥 |
| R2 草稿 | 首章在一页内给出行动、价格结论、概率、回报来源、反方和催化剂；正文将每一展品解释为“所以什么” | 首章是缺口声明、表格或作者工作说明 |
| R3 渲染/合规 | 图表可读、来源对读者可解释、全文日期与市场数据一致、假设与结果无矛盾 | 内部 source ID 不能映射到公告标题/日期/页码；价格日期混用 |
| R4 IC | 结论、目标、模型、风险、行动和残余不确定性互相一致；完整覆盖和事件研究的报告类型与签发状态一致 | 用“观察名单”或脚本 PASS 豁免投资判断；有重大模型缺口仍签发完整报告 |

## 给重建团队的优先顺序

1. 先决定路径 A 或 B，并把报告类型、签发标准和首页结构同步改掉。
2. 取得/核验 H1 正式资料；同时从完整卖方 PDF 提取 H1/H2 的数量、价格、成本与民爆假设，作为交叉验证而非结论替身。
3. 先完成结构化分部模型、三情景和估值，再写正文；所有正文数字从模型和来源表引用。
4. 最后制作 PDF 展品、读者可读来源附录和 R0--R4 复核。验证器应验证真实模型与报告的一致性，而不是用占位字段奖励“无模型”。
