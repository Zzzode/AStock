# Exhibit Plan — 雅化集团完整单票覆盖

| ID | 展品 | 支撑的结论 | 主要输入 | 验证规则 |
|---|---|---|---|---|
| E1 | IC 三情景与行动卡 | 回报来自何处、何时验证 | 自有估值模型 | 目标、上行与 JSON 一致 |
| E2 | H1 预告与外部 H2 要求 | 市场争论在持续性而非 Q2 本身 | 公司预告、完整券商 PDF | 不把卖方称为公司指引 |
| E3 | 2023A--2026E 利润与现金桥 | 利润修复需被现金验证 | 年报、Q1、模型 | H1 正式数据不得预填 |
| E4 | 锂盐单位经济桥 | 吨量、实现价格、成本决定 EPS | 年报、模型与商品价格 | 设计产能不替代销量 |
| E5 | 锂价与公司吨收入对照 | 行业价格只解释方向，不能替代 ASP | 价格资料、年报 | 资料级别显著标识 |
| E6 | 民爆产品/矿服利润池 | 防御性业务的范围与限制 | 年报分部资料 | 无订单/回款不作增量信用 |
| E7 | CFO—归母—营运资本桥 | 现金折价是否应保留 | 财报三表 | 数字可从财报复算 |
| E8 | 同行业务与估值 scorecard | 何种差异得到估值、何种只是叙事 | 同行财报和市场包 | 统一年度与口径 |
| E9 | 资源与客户证据矩阵 | 证实、推断和未披露的边界 | 公司披露与审计表 | 未证实行零信用 |
| E10 | 近期价格、成交与相对表现 | 交易位置和情绪风险 | 市场数据包 | 不把成交额说成资金方向 |
| E11 | 自有、卖方与市场隐含比较 | 预期差的来源 | 模型、卖方、行情 | 锚权重披露 |
| E12 | 三情景估值与敏感性 | 哪个变量真正影响目标价 | 结构化估值模型 | 数值和单位交叉校验 |
| E13 | 催化剂日历 | 何时重估与何时撤销 | 披露日程与模型阈值 | 每一项有行动后果 |
| E14 | 风险热图 | 影响和概率如何进入仓位纪律 | 风险模型 | 不能只列风险名称 |

所有核心结论均至少由一项表或图和紧随其后的解释段支持；最终渲染后检查编号、单位、数值一致性、裁切与可读性。
