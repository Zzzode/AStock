# 付费数据访问状态审计
## Paid Data Access Audit

> 评估各类付费数据平台的访问状态及其对功率半导体研究的影响
> 审计日期：2026-06-21
> 文件分类：AUDIT / EVIDENCE
> 覆盖平台：Wind, Choice, iFinD, Tushare, Bloomberg, 行业数据

---

## 一、审计范围与方法

对研究所需的各类数据类型，逐一评估各付费数据平台的覆盖情况、获取状态和对研究的影响。

### 2.1 Wind 万得（Wind）金融终端

## 三、数据需求与缺口

| 数据类型 | 现有获取方式 | 完整度 | 对研究影响 |
|---------|------------|-------|-----------|
| 上市公司财报 | 交易所公开披露 | 100% | 无影响 |
| 行情数据（日线） | Tushare / 公开网站 | 95% | 轻微 |
| 卖方研报原文 | 公开渠道 / 券商官网 | 40-50% | 中等 — 部分研报无法获取全文 |
| 一致预期数据 | 手动汇总研报 | ~30% | 中高 — 覆盖券商有限 |
| 机构持仓数据 | 季报前十大 + 基金季报 | ~40% | 中等 — 时效性和完整性不足 |
| 行业数据（市场规模等） | 国内研报间接引用 | ~50% | 中等 — 颗粒度不足 |
| 渠道价格/库存数据 | 券商研报 / 公开指数 | ~20% | 高 — 周期判断精度受限 |
| 国际投行研报 | 公开摘要 | ~10% | 中高 — 国际视角不足 |
| 海关进出口数据 | 海关总署公开 | ~30% | 中等 — 颗粒度不足 |

## 四、对研究结论的影响评估

### 4.1 影响程度评估

| 研究环节 | 数据完整性 | 对结论置信度影响 |
|---------|----------|----------------|
| 公司基本面分析 | 高（80%+） | 低 — 财报数据完整 |
| 行业规模与增长 | 中（50-60%） | 中等 — 依赖间接数据 |
| 估值分析 | 中（50-60%） | 中等 — 一致预期不足 |
| 周期判断 | 低（20-30%） | 高 — 价格/库存数据缺失 |
| 国际比较 | 低（10-20%） | 高 — 国际投行数据缺失 |
| 竞争格局分析 | 中（40-50%） | 中高 — 依赖二手数据 |

### 4.2 总体影响评级：中等偏高

研究的核心部分（公司基本面、估值）数据相对完整，
但行业数据、周期判断、国际比较等维度数据缺口较大。

## 五、建议

1. **核心结论需标注数据来源和置信度
2. 对数据缺口较大的领域（周期判断、国际比较）需明确说明数据局限性
3. 如预算允许，优先补充 Wind 终端（提升研报、一致预期、机构持仓）
4. 其次考虑行业报告（Yole/TrendForce）提升行业数据深度
5. Bloomberg 终端优先级相对靠后（对A股研究边际提升有限）
