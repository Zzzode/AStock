## 一、探针范围

覆盖功率半导体产业链的各类渠道数据获取情况，包括价格数据、库存数据、进出口数据、行业出货数据等。

## 二、各类数据探针详情

### 2.1 华强北价格指数

| 项目 | 详情 |
|------|------|
| **探针目标** | 获取功率半导体（IGBT、MOSFET、SiC）SKU级价格指数 |
| **访问路径** | 1. 华强北指数官网<br>2. 华强电子网/立创商城等交易平台<br>3. 行业媒体价格监测<br>4. IHS/WSTS专业价格数据 |
| **可获取数据** | - 分立器件大类指数的周度/月度走势<br>- 具体型号的零售报价（样品级）<br>- 季度/半年度价格趋势综述文章 |
| **无法获取数据** | - SKU级价格时间序列数据<br>- 渠道批量价格（区别于零售）<br>- 国产vs进口品牌价格差<br>- 分应用领域价格差异 |
| **可用性等级** | Public Aggregate Only（仅公开汇总数据） |
| **付费门槛** | IHS Markit / WSTS Premium 订阅（数千至数万美元/年） |
| **对研究的影响** | 无法进行精准的价格周期判断，价格拐点判断依赖间接数据 |
| **详细探针记录** | `sources/probe-failed/channel_huaqiangbei_index.md` |

## 四、对研究的影响

### 4.1 周期判断维度

- **影响程度：高

渠道价格和库存数据是判断半导体周期位置的核心指标。
当前数据状况：仅有定性判断和粗略估计，无法精确定位周期位置。
应对：使用上市公司财报数据（毛利率、存货周转、订单能见度）作为替代指标。

### 4.2 市场规模维度

- **影响程度：中等

可以通过国内券商研报间接获得大量第三方数据，但颗粒度和时效性不足。
应对：多家券商数据交叉验证，取共识区间。

### 4.3 国产替代维度

- **影响程度：中等

进出口数据颗粒度不足，无法精确量化国产替代进度。
应对：
使用上市公司国产相关收入增速 + 行业协会数据 + 券商研报综合判断。

## 五、结论

- **整体渠道数据可用性**：较差。公开渠道可获得的数据以汇总级和定性描述为主，
  颗粒度和时效性均不足。

- **核心缺口**：SKU级价格数据、渠道库存数据、细分进出口数据。

- **阻碍类型**：付费门槛 + 数据非公开。

- **建议**：
  1. 研究中明确标注渠道数据的局限性
  2. 周期判断使用多指标交叉验证，提高结论稳健性
  3. 如预算允许，优先考虑行业研究报告（Yole/TrendForce）
  4. 价格数据可考虑 IHS Markit 作为长期数据补充
