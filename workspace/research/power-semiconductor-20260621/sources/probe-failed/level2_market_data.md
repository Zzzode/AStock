# 探针失败记录：Level-2 实时市场数据（功率半导体板块）

## 探针基本信息
- **探针日期**：2026-06-21
- **探针目标**：获取 A 股功率半导体板块的 Level-2 高频行情数据（盘口、逐笔成交、委托队列等）
- **探针人**：AStock Research
- **状态**：失败 — 本环境无 Level-2 数据权限

## 尝试路径

### 路径 1：交易所官方数据接口
- **方法**：查询上交所、深交所 Level-2 行情数据获取方式
- **获得结果**：
  - 交易所 Level-2 行情为付费增值服务
  - 需通过券商或信息服务商订阅
  - 包含：十档盘口、逐笔成交、委托队列、买卖盘揭示等
- **为什么不够**：
  - 需付费订阅，本研究环境无权限
  - 数据费用较高（个人版约数百元/年，机构版更高）
  - 数据量大，需要专门的存储和处理系统

### 路径 2：券商高级行情服务
- **方法**：查询各大券商的 Level-2 行情服务
- **获得结果**：
  - 多数券商提供 Level-2 行情（免费或收费）
  - 部分券商对新开户客户免费赠送
  - 包含行情软件和移动端 APP
- **为什么不够**：
  - 需开通证券账户并满足一定条件
  - 仅能通过券商软件查看，无法批量导出数据
  - API 接口需机构客户权限，个人投资者无法获取
  - 无法进行量化分析和历史回测

### 路径 3：第三方数据服务商
- **方法**：查询 Tushare、聚宽、米筐等量化平台的 Level-2 数据
- **获得结果**：
  - 部分量化平台提供历史 Level-2 数据
  - 需高级会员权限，费用较高
  - Tushare 免费版无 Level-2 数据
- **为什么不够**：
  - 免费额度不足以支撑研究需求
  - 历史数据回溯有限
  - 数据更新频率和完整性不如交易所直接接口
  - 费用：Tushare 高级版约 1000-3000 元/年

### 路径 4：免费行情软件
- **方法**：使用同花顺、东方财富等免费行情软件
- **获得结果**：
  - 免费版提供五档盘口和分时成交
  - 部分软件提供有限的 Level-2 试用
  - 可查看实时行情走势
- **为什么不够**：
  - 仅有五档盘口，无十档和委托队列
  - 无逐笔成交明细数据
  - 无法导出数据进行深入分析
  - 数据刷新频率较低

### 路径 5：Level-2 数据的研究价值评估
- **方法**：评估 Level-2 数据对本研究的实际价值
- **获得结果**：
  - Level-2 数据主要用于短线交易和量化策略
  - 对于中长期基本面研究价值相对有限
  - 机构持仓和资金流向分析可通过其他数据替代
- **为什么仍需关注**：
  - 可用于验证市场情绪和资金动向
  - 可辅助判断关键价位的支撑/压力
  - 大单流向分析有助于理解机构行为

## 结论
- **可用性等级**：No Access（本环境无权限）
- **付费门槛**：数百元至数千元/年（不同等级）
- **对研究的影响**：
  - 短线交易分析和市场微观结构研究无法进行
  - 实时资金流向分析精度受限
  - 买卖盘力量对比分析只能基于五档数据
  - 对中长期基本面研究影响有限

## 替代方案
- 使用免费行情软件的五档盘口数据做定性分析
- 使用日成交量和换手率数据判断资金活跃度
- 通过龙虎榜数据观察大额交易（但频率低）
- 使用融资融券数据辅助判断市场情绪
- 关注大宗交易数据了解机构间换手
