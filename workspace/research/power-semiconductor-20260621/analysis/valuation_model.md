# 估值模型

## 估值方法论

### PE 估值法
- **适用**：成熟盈利型公司（IDM 龙头、IGBT/MOSFET 龙头）
- **行业区间**：一线龙头 45-70x，二线成长 30-55x，三线 50-100x
- **注意**：功率半导体周期性强，PE 在周期底部高但估值便宜，周期顶部低但估值贵

### PS 估值法
- **适用**：亏损或微利的第三代半导体公司、周期底部公司
- **行业区间**：成熟公司 2-6x，高成长第三代半导体 8-20x
- **核心锚**：Wolfspeed PS ~2.5-3.5x，Navitas PS ~5-7x

### PEG 估值法
- **适用**：成长期公司
- **合理 PEG**：A股功率半导体 1.2-1.8（含成长溢价），SiC/GaN 可给到 2.0-3.0

### EV/EBITDA 估值法
- **适用**：重资产 IDM 公司、周期股跨周期比较
- **行业区间**：全球成熟公司 10-18x，A 股 IDM 15-25x

### DCF 估值法
- **适用性**：较弱，因周期性强、技术迭代快、资本开支波动大

### A 股溢价分析
A 股功率半导体估值较海外普遍溢价 2.5-3 倍，核心原因：
1. **国产替代成长溢价**：增速是海外 2-3 倍
2. **流动性溢价**：A 股科技股流动性充裕
3. **主题催化溢价**：AI/SiC/新能源持续催化
4. **稀缺性溢价**：优质标的数量有限

## 估值结论与操作建议

### 当前估值判断
- **整体板块**：不算便宜，但也未到泡沫区间
- **结构性机会大于指数性机会**
- 优选**低估值 + 高确定性**的标的

### 配置策略
- **核心配置（60-70%）**：时代电气、扬杰科技 — 估值合理、业绩确定
- **弹性配置（20-30%）**：斯达半导、新洁能 — 周期复苏弹性
- **主题配置（≤10%）**：三安光电、天岳先进 — 高风险高弹性

### 关键观察信号
- 毛利率环比企稳 → 周期确认 → 加仓
- 国际大厂交期延长 → 供需改善 → 加仓
- AI 服务器出货量超预期 → 主题催化 → 加仓
- 行业库存去化完成 → 利润弹性释放 → 加仓
- 业绩低于预期 → 估值下修 → 减仓
