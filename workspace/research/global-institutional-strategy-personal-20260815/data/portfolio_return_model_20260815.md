# Portfolio / Return-Model Boundary

This is not a forecast model. It records the only auditable present state: `q=0` for all market exposures and 100% protected liquidity as an inactive evidence fallback. It does **not** predict a cash yield or a return.

| Sleeve | Current weight | Status | What would have to exist before a separate review |
| --- | ---: | --- | --- |
| Protected liquidity | 100% | Inactive fallback | It remains only because individual evidence is absent. |
| Domestic-futures CTA | 0% | Formal test blocked | Contract, broker, data, cost, margin and risk dossier. |
| A-share factors | 0% | Formal test blocked | Point-in-time data, portfolio constraints, costs and risk dossier. |
| Public-information events | 0% | Formal test blocked | Primary timestamps, event universe, costs and invalidation replay. |
| Calendar/RV | 0% | Formal test blocked | Two-leg, roll, delivery, margin and failed-exit dossier. |
| Crypto economic research | 0% | Not approved | Jurisdiction/access, product, custody, venue, tax and risk dossier; no mainland route. |

Cash receipts, return-of-capital-like flows, reinvestment and total return are defined in the JSON to prevent double counting. No risk budget, loss limit or implementation approval exists.
