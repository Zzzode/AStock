# Broker Target-Price Scope Note

This strategic allocation case does not issue a current-price target for any individual security. Its core conclusion is a category-level allocation framework using cash, government-bond, dividend-equity, gold and optional REIT sleeves. Consequently, no broker target-price corpus was collected or used as a valuation anchor.

All representative ETF/product rows are explicitly zero-weight for broker evidence. A future direct-stock or individual-REIT recommendation requires a separate case with current market price, financial/prospectus evidence, a method-fit valuation and an auditable external anchor where available.
