# 战略配置模型

## 资金口径：固定CNY20万就是全额可投资本金

用户已明确：固定CNY200,000是独立、全额的投资本金，不需要也不会从中再扣除家庭安全垫、生活费或未来支出。因此本报告直接定义：

\[
V=V_{hand}=\text{CNY200,000}.
\]

本报告不计算家庭安全垫，也不将任何外部家庭资金、支出或负债从 $V$ 中扣减；这些项目不属于本次组合建模范围。下文所有百分比与金额表均直接作用于这笔 $V$，不存在“先扣一笔钱再按比例配置”的前置条件。

组合内部的“受保障流动性”和“交易现金”都是 $V$ 中的资产层，合计目标25%，服务于分批建仓、再平衡与降低被动卖出风险；它们不是要求投资者在组合外另留一笔钱。“交易现金”最多5%（固定CNY200,000下为CNY10,000），可使用存款或经核验的货币工具，但其不是存款保险保障的同义词。任何ETF未通过执行日核验的金额唯一留在受保障流动性，不得挤入交易现金或自动改配其他风险资产。

## 三个核心目标向量

|---|---:|---:|---:|---|
| 组合内受保障流动性 | 40% | 20% | 10% | 存款/到期前直接政府债为主；属于 $V$ 内的防守资产 |

| 高质量人民币利率债 | 35% | 35% | 30% | 防守性、利率分散和再平衡弹药 |
| 红利权益ETF | 10% | 30% | 35% | 长期实际回报与可选择现金分配 |
| 更广泛权益ETF | 0% | 0% | 10% | 仅在七年以上、可承受更高回撤时降低红利因子单一性 |
| 非杠杆黄金ETF | 10% | 10% | 10% | 宏观风险分散，不计入收入预算 |

| 合计 | 100% | 100% | 100% |  |

基准稳健**核心版**是本报告的默认答案：25%组合内流动性（20%受保障流动性 + 5%交易现金）、35%高质量利率债、30%红利权益ETF、10%非杠杆黄金ETF。保守版适合未来3--5年可能用钱或无法承受约12%临时回撤者；稳健增长版只适用于七年以上资金、稳定追加且能承受约25%级别账面回撤者，不能描述为低风险。

### REITs 只在单独激活的向量中出现

只有同时满足以下条件，才可由“核心版”切换至“REITs已激活版”：

1. 至少三只彼此独立、已完成项目现金流、债务、出租率/收费量、估值溢价及流动性审查的公募REITs均可交易；
2. 每只不超过总组合2%，合计不超过5%，且最小交易单位、价差和费用不使三只分散在固定CNY200,000规模下失去经济性；
3. 不存在任何单一项目或管理人集中度红线。

满足后，基准稳健或稳健增长的**利率债权重精确下调5个百分点，REITs上调至5%**；其余权重不变。未同时满足时，$w_{REIT}=u_{REIT}=0$，该5个百分点永远留在利率债，不允许因“等待分红”自动买入REITs。小规模下无法经济地做到三只分散时，正确配置就是0%。

### 全资产层的 $w/u/q$ 控制表

$w$ 是活动目标，$u$ 是硬上限，$q$ 是执行时资格开关。只有 $q=1$ 的资产层可收到新增资金；任何产品、集中度或法律文件检查失败均令相应 $q=0$。下表按“保守 / 基准核心 / 基准REITs激活 / 增长核心 / 增长REITs激活”列示 $w$，因此每一个活动向量都可复算。

| 资产层 | $w$：保守 / 基准核心 / 基准REITs / 增长核心 / 增长REITs | $u$ | $q=1$ 的必要条件 |
|---|---|---:|---|
| 组合内受保障流动性 | 40% / 20% / 20% / 10% / 10% | 100% | 合格存款或期限匹配直接政府债可用；也唯一承接未通过ETF核验的余额 |
| 交易现金 | 5% / 5% / 5% / 5% / 5% | 5% | 存款或已完成流动性、费用和非存款风险核验的货币工具；不得接收超出CNY10,000上限的延后资金 |
| 高质量利率债 | 35% / 35% / 30% / 30% / 25% | 60% | 质量、久期、费用和流动性均通过执行日资格包；不含信用下沉或伪现金产品 |
| 红利权益ETF | 10% / 30% / 30% / 35% / 35% | 35% | 510880产品核验通过；512890另须通过合并持仓的行业、集团和基金上限 |
| 更广泛权益ETF | 0% / 0% / 0% / 10% / 10% | 10% | 仅增长版，且文件、流动性和因子重叠检查通过 |
| 非杠杆黄金ETF | 10% / 10% / 10% / 10% / 10% | 12% | 非杠杆现货ETF、费用和折溢价检查通过 |
| 公募REITs | 0% / 0% / 5% / 0% / 5% | 0% 或 5% | 未激活时 $q=u=0$；激活时至少三只独立项目通过全部项目与交易可行性审查 |

“受保障流动性”是唯一允许因瀑布残余而高于 $w$ 的层，其 $u=100\%$ 是刻意设定的安全上限，而非风险加仓许可。交易现金上限为5%（CNY10,000）；所有超出该上限的延后或取整余额仍归入受保障流动性而不是货币基金/ETF。执行日资格包、字段、来源、时间戳和受控阈值见 `data/execution_eligibility_policy_20260812.json`；当前状态为 `not_run`，并不代表任何ETF已合格。

## 六个月建仓算法

因未获得合格的当前市场包，本模型不做高低点判断，且所有ETF的执行日资格开关当前为$q=0$。

1. 选定唯一的活动目标向量（核心版或已激活REITs版）；
2. 对基准稳健核心版，先建立组合内受保障流动性20%和交易现金5%；511010仅在$q=1$时建立。红利权益和黄金合计CNY80,000，分为六个等额月份，每月约CNY13,333，最后一笔按余额补齐；
3. 若REITs在第一笔风险资产前已通过全部激活条件，则先配流动性25%与利率债30%，红利权益、黄金和REITs合计CNY90,000，分六个月、每月CNY15,000实施；若未通过，不能在建仓中途把债券额度自动换成REITs；
4. 若某只ETF当日出现异常折溢价、价差、停牌、流动性不足或资料不全，该月份只延后，资金唯一转入受保障流动性；不以另一只高相关资产、511010或超过上限的交易现金替代；
5. 第六个月前未满足REITs激活条件，则永久使用核心版，直至下一次独立复核后才可更换活动向量。

## 年度追加资金和再平衡算法（含硬上限）

设追加前组合市值为 $V$，年度新增资金为 $C$，追加后总额为 $V^+=V+C$，活动目标权重为 $w_i$，硬上限为 $u_i$，当前持仓为 $H_i$。例如，红利权益 $u=35\%$、黄金 $u=12\%$，而未激活REITs时 $u_{REIT}=0$、激活后才为5%。只有通过产品和集中度检查的资产层令 $q_i=1$，其余为0。

\[
d_i=q_i\times\min\left(\max(0,w_iV^+-H_i),\max(0,u_iV^+-H_i)\right).
\]

若 $\sum_i d_i\ge C$，按 $x_i=C\times d_i/\sum_i d_i$ 分配；若 $\sum_i d_i<C$，仅投入 $x_i=d_i$，余下的 $C-\sum_i d_i$ 留在组合内受保障流动性，直至下一次再平衡。该瀑布式规则用 $V^+$ 而非追加前 $V$ 计算，且不会向未激活REITs、已超硬上限或未通过集中度检查的风险桶投入新钱；交易现金不因这类余额超过5%。

若某风险桶已经违反硬上限，令其 $q_i=0$、暂停新增，并启动人工复核；不得把“下跌”或“历史高分红”当作绕过上限的理由。每季度只测量；每半年常规再平衡。受保障流动性、利率债或总权益相对活动目标偏离超过5个百分点，交易现金超过CNY10,000或在分批期内低于目标，黄金偏离目标超过2个百分点，或REITs超过活动目标/单项目上限时启动复核。再平衡优先用新增资金、利息与分配完成，避免把价格下跌自动等同于加仓信号。实际回撤控制只适用于按账户价值记录的$DD_t$，不由压力情景数字自动触发。

## 模型边界

权重是风险预算而不是收益预测。它不包含房产、职业收入、社保、商业保险、现有基金或负债的全资产负债表，也不据此重新扣减本报告的 $V$。若这笔资金后来被改作三年内支出、购房、教育、医疗或债务偿付，应停止按本策略自动追加，并另行建立对应用途的资金计划；不是把原组合再套一个扣减公式。
