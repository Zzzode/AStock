\begin{houseviewbox}[先说结论]
这20万元在本模型中是五年以上的全额投资本金，不是固定生活费账户。组合采用ETF/资产层优先的方式：直接股票和公募REITs开始时均为0\%。长期年化3\%--6\%只是复利敏感性区间，不是保证；在共同承压的规划测试中，20万元可能出现约CNY32,600的账面损失，实际情况也可能更差。
\end{houseviewbox}

\section*{二、怎样做分阶段研究}

\begin{enumerate}[leftmargin=1.7em,itemsep=0.2em]
  \item 先确认这20万元在未来五年以上不需要改作刚性支出，并核对产品文件、费用、交易规则和适当性。
  \item 模型先建立CNY120,000防守层：CNY40,000受保障流动性、CNY10,000交易现金、CNY70,000利率债。
  \item 红利权益ETF和黄金合计CNY80,000按六个月研究节奏分阶段补足，每月约CNY13,333，最后一个月按余额校正。
  \item 如果出现产品资料缺失、异常折溢价、停牌、明显价差或流动性不足，当月只延后；不以另一只高相关资产替代。
\end{enumerate}

这是一张研究模板，不提供外部下单时间、价格、数量或通道。示例产品必须在实施日前重新核对法律文件、净值相关数据、折溢价、价差、流动性和组合穿透。

\section*{四、能不能给家人固定现金}

不能在今天预先承诺。每季度只记录过去12个月已经到账、税后并扣费后的现金 $D_0$；实际分配减少时，首先只是再投资现金减少，并不应该靠卖出防守资产、杠杆或追高来补足。若未来需要为家人提供固定生活费、教育费或医疗费，应先另行建立用途、期限、税后现金流和风险承受计划，不能把历史股息率当作工资。

\section*{五、什么时候暂停}

\begin{itemize}
  \item 资金用途从长期积累改为三年内刚性支出时；
  \item 总权益、流动性或利率债偏离目标5个百分点，或黄金偏离目标2个百分点时；
  \item 组合账面损失达到12\%复核线时，停止自动增加风险资产；
  \item 想增加直接股票或REITs时，尚未完成独立估值、现金流、集中度、流动性和税务审查时。
\end{itemize}
