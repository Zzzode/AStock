# R5 公开累计净值绝对动量探索性可行性检验 — 2026-08-15

- 文档 ID：`DPSFS-R5-PNAV-v1`
- 状态：`exploratory_post_observation_not_a_clean_preregistration`
- 性质：单次、研究性历史可行性检验；不是正式回放、产品准入、组合建议或外部操作。

## 问题与边界

本检验问的是：对五个已在本案例 R0 官方产品资料中留档的代表性场内基金，若以公开页面显示的**累计净值**作为未经独立验证的经济回报代理，并按一条固定的月度绝对动量规则处理，是否会在该受限代理口径下通过严格的历史否决门槛。它不是对投资者成交回报、未来收益或任何个人账户结果的检验。

本检验不设资金规模、资金流出目标或额外再投入条件；所有计算以初始值为 1 的无量纲单位净值进行。公开“累计净值”字段的定义、复权、现金事件覆盖及修订链必须由后续资料核实，不能因为字段名称而被当作完整投资者总回报。

候选代码都已存在于本案例的 `E01--E05` 官方产品资料记录中：

| 经济袖套 | 固定实现代码 | R5 中的角色 |
|---|---|---|
| 中国股票 | `510300`、`510880` 各半 | 一个权益袖套；两只基金不分别排序 |
| 国债利率 | `511010` | 一个债券袖套 |
| 黄金 | `518880` | 一个商品袖套 |
| 货币市场 | `511990` | 仅在没有风险袖套合格时的规则化替代工具 |

这不是完整 U0、历史总体或推荐清单。五只产品也没有因此获得准入；其当前产品级尽调另行进行。

### 预观察披露

在本规则书写定前，本研究会话曾用 `akshare.fund_etf_fund_info_em` 对 Eastmoney 页面是否返回历史净值字段进行可用性检查，并查看过至少部分代码的样例/历史响应；该检查没有保存为 R5 原始档案，也没有运行本规则、计算组合数值或据结果选择参数。尽管如此，它已经破坏了“在看到任何相关历史响应前预注册”的严格条件。

因此本文旧文件名中的“预先声明”仅是创建时的命名，**不能被理解为干净预注册**。R5 被降级为 `exploratory_post_observation_not_a_clean_preregistration`：它可以提供一个对既定规则不利的负面观察，不能把任何正面结果当作独立样本外、策略证据或行动依据。

## 与已停止 H01--H07 的区别

H01--H07 用四条公开**收盘价**序列进行相对动量、前 N 名选择、多个回看/风险预算变体及防守映射。R5 不读取其原始数据、参数、结果或任何幸存者判断，也不改变其停止状态。

R5 的唯一规则改为：单一公开累计净值字段、三个经济袖套的独立绝对动量、无相对排名、无前 N 名、无参数网格、无风险预算变体；权益始终作为一个双产品等分袖套，而不是把两个权益产品当作相互竞争的资产。该差异只使它成为一个新的、受限的研究问题，不使其成为独立样本外或可用策略证据。

## 单一固定规则

1. 在本次完整、可核验归档抓取前，单一来源路径固定为 Eastmoney 场内交易基金历史净值接口；每个代码只读取 `FSRQ`（净值日期）、`LJJZ`（页面显示累计净值）、页面响应本身及接收时间。完整请求模板、原始响应哈希和解析版本必须归档。
2. 将五只基金按日期取共同的正值累计净值面板；任何缺日、非正值、重复日或页面异常均保留为失败/覆盖状态，不由第二来源补写。
3. 每月最后一个共同观察日，以当日与此前第 252 个共同观察日的累计净值比计算各经济袖套的绝对动量。权益信号袖套是 `510300` 与 `510880` 从共同面板首日各 50% 起始权重构成的**固定基期、买入持有型等权水平**，期间不为信号本身再平衡；债券和黄金袖套各由其唯一基金代表。若权益袖套被选中，策略目标权重才在该次调仓时重置为两只基金各半；这与信号指数口径是两个不同概念。
4. 动量严格大于零的袖套为合格袖套。所有合格袖套在下一共同观察日等权持有；若三个袖套均不合格，则下一观察日仅持有 `511990`。不做横截面排序、主观覆盖、杠杆、借贷、期货或期权扩展。
5. 每个调仓按漂移后权重与目标权重的单边换手计一次固定 `20bp` 研究性成本载荷。该载荷不是经纪费率、税费、点差、冲击或可成交性证据；其作用仅是防止把零成本净值切换误称为保守结果。
6. 信号在月末观察后形成，目标只能在下一共同观察日生效；当天净值不得被同时用于信号和生效回报。每日先按已生效权重更新单位净值，再记录月末信号。

## 固定评估与否决条件

输出必须同时报告：全期年化、最大回撤、完整自然年净单位化收益、每个满 1,260 个共同观察间隔的滚动五年年化净单位化收益、换手及覆盖异常。

`5%` 仅是这一条固定研究规则的严格历史否决线：每个完整自然年和每个合格滚动五年端点都必须达到或超过 `5%`，且没有输入/会计失败，才可记为 `PUBLIC_NAV_PROXY_HURDLE_NOT_FALSIFIED`。任一条件不满足即为 `PUBLIC_NAV_PROXY_HURDLE_FALSIFIED`。由于本协议不是干净预注册，前一种状态不能作为正面策略证据；后一种状态只能作为避免误把该固定代理规则说成“稳定 5%”的负面研究记录。两种状态均不构成收益承诺、概率判断、产品推荐或可交易结论。

## 已知不可跨越的限制

- 该来源是事后抓取的公开聚合页面，不证明原始可得时间、修订历史、字段口径、留存/衍生分析权利或全历史完整性。
- 基金累计净值不是场内可成交价格；市场价与 NAV/IOPV、申赎、分配、停复牌、涨跌停、T+0/T+1、最小单位、深度、未成交、税费和结算均未由本检验建模。
- 代表性五产品存在当前可得性与幸存者偏差，不能代表 U0，也不能产生全市场配置结论。
- 即使代理口径未被否决，仍须通过产品尽调、经纪规则核验、获权 PIT/事件/执行数据、正式成本后回放、独立复算与前瞻纸面核对，才可讨论个人行动可行性。

因此本协议的唯一允许输出是一个可证伪的研究记录，而不是“稳定 5%”策略。
