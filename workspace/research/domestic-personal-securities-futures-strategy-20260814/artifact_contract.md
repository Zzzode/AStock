# Artifact Contract

The machine-readable authority is artifact_contract.json (version v6). This
interim case is not publish-bound. Its artifacts establish source governance,
candidate identity, universe/protocol/data boundaries and explicit blockers;
they do not establish an allocation, holding list or return result.

| Artifact | Stage | Minimum fields | Blocks upgrade when missing |
|---|---|---|---|
| Research brief | Intake | Mandate, scope, candidate universe, hard boundaries, upgrade path | Yes |
| Source manifests | Evidence | Publisher, URL, path, date, size, hash, use boundary | Yes |
| Source registry and claim audit | Evidence | Authority, quality, claim scope, limitation, prohibited inference | Yes |
| Draft T2 universe and rulebook | Model definition | Identity, role, timing, event/cost/no-fill treatment, q | Yes |
| Data-acquisition contract | R1 data governance | Version/freeze, entitlement, schema, availability, coverage, lineage, non-self-referential row-bound canonical freeze, a/s/e unit-NAV endpoint, holdout component, fill/state/depth, fee-tax/FX/settlement, paired cash/margin/collateral transfer, daily-margined futures and FAILED controls, reservation-pool/economic-NAV and state-coverage controls, UR01--UR05 matrix | Yes |
| Data-access feasibility audit | R1 access-feasibility audit | Scope boundary, route decision, UR01--UR03/U0 gap matrix, evidence IDs, minimum external prerequisite, q/no-action boundary | Yes |
| Missing-data request pack | R1 external-dependency specification | UR01--UR03/U0 matrix, six-class future-module capability request, PIT/revision/rights, delivery/manifest, acceptance, roles, not-sent q/no-action boundary | Yes |
| U0 domestic-universe registry | R1 universe governance | Class status, population path, gates, survivorship, intake, q | Yes |
| U0-to-T2 derivation audit | R1 universe-to-selection governance | Snapshot, counts, parent mapping, rule/reasons, exceptions and coverage label | Yes |
| Formal replay-protocol requirements | R1 protocol governance | Strict test statistic, PIT/blinding, a/s/e unit-NAV TWRR, overlap/regime boundary, holdout row-level start state, non-self-referential frozen-run binding, execution/settlement/fill/depth/FX controls, paired-transfer/signed-unsettled/FAILED and daily-margined futures controls, endpoint population/status counts, reservation feasibility, risk/feasibility, anti-leakage, output and entry controls | Yes |
| Replay data-dictionary template | R1 normalized-data design | Keys, types, units, provenance, non-self-referential row-bound freeze, fill/state/capacity/fee-tax/FX/settlement linkage, transfer-pair/dated-term/signed-unsettled/FAILED and futures-daily-margin fields, economic unitization/position/lot/reconciliation distinct from reservations, a/s/e endpoint population and holdout-component/coverage-audit tables | Yes |
| ETF/futures R1 analysis | Product/futures diligence | Structure, mechanics, risks, gaps, R2 gate, q | Yes |
| R1 open-universe coverage and primary-source routes | R1 open-universe coverage | All ten U0 classes, evidence/gap matrix, first-party routes, PIT/replay/right gaps, future archive path and q/no-action result | Yes |
| R1 model review and repair plan | R1 model review | Initial/final status, field-level findings, independent verification, open external blockers, no-inference boundary and owner tasks | Yes |
| Interim evidence memo | Handoff | Supportable conclusions, rejected shortcuts, next tests, q and no-action boundary | Yes |

No artifact may silently turn a source, model proxy, convenient class subset or
data-access description into an investment claim.
