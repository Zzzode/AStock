## 第一部分: 龙芯中科 (688047.SH)

### 1.1 公司概况

| 项目 | 内容 |
|------|------|
| 股票代码 | 688047.SH (科创板) |
| 主营业务 | 龙芯系列 CPU 处理器研发、生产和销售 |
| 技术路线 | 自研 LoongArch 指令集架构 (完全自主指令集，非 x86/ARM 授权) |
| 产品线 | 龙芯 3A5000/3C5000 (服务器)、3A6000 (桌面)、2K0500 (嵌入式) |
| 2025A 营收 | 约 16.5 亿元 (YoY +28%) |
| 2025A 净利润 | 约 1.2 亿元 (扭亏) |
| 市值 (2026-07-01) | 约 450-500 亿元区间 |

**技术路线核心特征**:
- LoongArch 是龙芯中科完全自主设计的指令集架构，不依赖 x86 (Intel/AMD) 或 ARM 授权
- 与海光信息 (x86 授权)、飞腾 (ARM 授权) 形成差异化
- 优势: 完全自主可控，无外部授权风险；劣势: 软件生态成熟度远低于 x86/ARM
- 最新 3A6000 采用 12nm 工艺，IPC 性能接近 Intel 第 10 代酷睿水平

### 1.2 AIDC 相关业务

龙芯 CPU 在 AIDC/智算中心的应用场景:

| 应用场景 | 具体产品 | 收入纯度 | 证据状态 |
|----------|----------|----------|----------|
| 国产算力服务器 CPU | 龙芯 3C5000/3D5000 (16-32 核服务器 CPU) | 低 (<15%) | 政企/信创订单为主，AIDC 直接收入未单独披露 |
| 智算中心管理节点 | 3A5000 系列作为 BMC/管理平面 CPU | 极低 | 概念映射为主，无直接收入证据 |
| 信创云/政务云主机 | 3A6000/3C5000 在政务云、行业云的服务器部署 | 中 (信创口径) | 信创采购框架内，非 AI 训练专用 |

**关键判断**: 龙芯中科当前 AIDC 收入纯度极低。其服务器 CPU 主要应用于信创/政务领域的通用计算，而非 AI 训练/推理加速。在 AIDC 价值链中，龙芯更接近"国产算力平台"的 CPU 补充选项，而非 AI 加速器核心。

### 1.3 龙芯中科 vs 海光信息对比

| 维度 | 龙芯中科 (688047) | 海光信息 (688041) |
|------|-------------------|-------------------|
| **指令集架构** | LoongArch (完全自研) | x86 (AMD 授权，永久授权) |
| **生态成熟度** | 低 — 需自建应用生态，操作系统/编译器适配工作量大 | 高 — 完全兼容 x86 生态，Windows/Linux 原生支持 |
| **AI 加速器产品线** | 无独立 GPU/AI ASIC，与天数智芯等合作适配 | 海光 DCU (深算系列)，基于 AMD CDNA 架构 |
| **服务器 CPU 性能** | 3C5000: 32 核，12nm，SPEC 分数约为海光 7285 的 60-70% | 7285: 32 核，7nm 工艺，性能接近 Intel Xeon 中端 |
| **客户群** | 党政军信创、关键基础设施 (电力、交通)、教育科研 | 互联网云厂商、运营商、金融、政企智算中心 |
| **AIDC 收入纯度** | 低 — 信创通用计算为主，AI 加速场景少 | 中高 — DCU 直接用于 AI 推理/训练，已进入互联网云厂商供应链 |
| **2026E 营收预期** | 22-25 亿元 (信创招标节奏驱动) | 200-210 亿元 (DCU 放量 + CPU 稳健) |
| **估值信用** | 观察名单 (卫星观察池) | 盈利信用 (核心池) |
| **国产化程度** | 最高 — 指令集到微架构全自研 | 高 — 架构设计自研，x86 授权永久有效 |
| **制裁风险** | 低 — 不依赖外部 IP 授权 | 中 — AMD 授权受中美关系影响，但永久授权条款提供缓冲 |

**核心差异总结**:
1. **生态壁垒**: 海光 x86 生态是其最大护城河，龙芯 LoongArch 生态建设需要 5-10 年持续投入
2. **AI 纯度**: 海光有独立 DCU 产品线且已放量，龙芯无 AI 加速器产品
3. **客户结构**: 海光已进入互联网云厂商 (市场化客户)，龙芯集中在党政军信创 (政策驱动客户)
4. **自主可控等级**: 龙芯在最严格的信创场景 (完全自主可控要求) 具备不可替代性

### 1.4 纳入卫星观察池的理由和条件

**纳入理由**:
1. 国产 CPU 自主可控最纯粹标的，LoongArch 架构战略价值在中美科技脱钩背景下持续提升
2. 3A6000 性能突破 (12nm IPC 追平 Intel 10 代酷睿) 标志着自研架构进入可用阶段
3. 信创 2.0 (行业信创) 扩容带来服务器 CPU 增量需求，龙芯在电力、交通等关键行业有卡位优势
4. 与华为鲲鹏、飞腾 (ARM) 形成国产 CPU 三足鼎立格局

**升级到条件观察池的触发条件**:
- [ ] 服务器 CPU 出货量季度环比 >30%，且有非信创行业客户 (金融/互联网) 突破
- [ ] 披露 AIDC/智算中心相关收入占比 >10%
- [ ] 与国产 AI 加速器 (寒武纪/海光 DCU/昇腾) 的适配方案获得规模化部署
- [ ] LoongArch 生态关键软件 (数据库、中间件、AI 框架) 适配数量突破 5000 款

**当前估值信用**: 观察名单 (卫星观察池) — 有战略价值但 AIDC 收入纯度不足，不能给予盈利信用。

## 第二部分: 华为昇腾产业链 A 股映射

### 2.1 华为昇腾概况

华为昇腾 (Ascend) 是华为面向 AI 计算的全栈产品体系:

| 产品层级 | 具体产品 | 定位 | 状态 |
|----------|----------|------|------|
| **AI 芯片** | 昇腾 910B/910C | 训练芯片 (对标 NVIDIA A100/H100) | 910B 量产，910C 迭代中 |
| | 昇腾 310P/310B | 推理芯片 (对标 NVIDIA T4/L4) | 量产，规模部署 |
| **板卡** | Atlas 300T/300I | 训练/推理板卡 | 量产 |
| **服务器** | Atlas 800 训练服务器 | 8 卡训练整机 | 量产 |
| | Atlas 800 推理服务器 | 推理整机 | 量产 |
| **集群** | Atlas 900 SuperCluster | 万卡级 AI 训练集群 | 已部署 (鹏城云脑、武汉等) |
| **软件栈** | CANN (Compute Architecture for Neural Networks) | AI 计算架构 (对标 CUDA) | 持续迭代，CANN 7.0 |
| | MindSpore | AI 框架 (对标 PyTorch/TensorFlow) | 开源，社区活跃 |
| | MindFormers/MindSpeed | 大模型工具链/训练加速库 | 快速迭代 |

**市场地位估算** (2025-2026 中国 AI 加速器市场):
- NVIDIA: ~70-75% (含 A100/H100 走私/灰色渠道 + L40S/RTX 4090 等替代方案)
- 华为昇腾: ~15-20% (国内训练+推理合计，政企/运营商为主)
- 海光 DCU: ~5-8%
- 寒武纪: ~3-5%
- 其他 (摩尔线程、天数智芯等): <3%

> 注: 以上为行业研究机构 (IDC、Counterpoint) 综合估算，非官方数据。华为未单独披露昇腾收入。

### 2.5 华为昇腾 vs NVIDIA 生态市场份额趋势

| 指标 | NVIDIA 生态 | 华为昇腾生态 |
|------|------------|-------------|

3. **风险因素**: 美国进一步制裁中芯国际 (14nm 以下设备禁运)、华为海思设计团队稳定性、CANN 软件生态建设速度

### 3.3 国产替代关键结论

1. **最确定的国产替代赛道**: 内存接口芯片 (澜起科技全球领先)、AI 服务器整机 (浪潮/工业富联全球份额高)、高速光模块 (中际旭创全球龙头) — 这些环节 A 股公司已具备全球竞争力，估值信用最高

2. **政策驱动最强但技术差距最大的赛道**: AI 训练芯片 (GPU/ASIC) — 国产化率最低但政策支持力度最大，寒武纪/海光 DCU/昇腾是核心标的，但性能差距意味着短期内不能完全替代 NVIDIA

3. **信创驱动的 CPU 赛道**: 海光 (x86) > 飞腾 (ARM) > 龙芯 (LoongArch) — 按生态成熟度排序。但在最严格的自主可控场景下，龙芯的 LoongArch 不可替代

4. **"卡脖子" 最严重的环节**: HBM (几乎 100% 进口)、先进制程代工 (中芯国际 14nm 以上受限)、EDA 工具 (国产替代率 <10%) — 这些环节 A 股缺乏高纯度映射标的

5. **昇腾产业链的投资价值排序**:
   - 第一梯队 (已在核心池): 华工科技、中际旭创 (光模块，昇腾增量锦上添花)
   - 第二梯队 (条件观察池): 神州数码、拓维信息 (昇腾服务器/解决方案，纯度较高但需验证)
   - 第三梯队 (观察名单): 广电运通、软通动力、润和软件、常山北明 (纯度低或双主业摊薄)
