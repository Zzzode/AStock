## 图表1: 目标价上行/下行空间分布条形图

| 属性 | 说明 |
|------|------|
| **chart_id** | `chart1_upside_distribution` |
| **标题** | AIDC产业链标的目标价上行/下行空间分布 |
| **类型** | bar (水平分类条形图) |
| **数据来源** | `data/combined_target_valuation_model_20260701.json` → `rows[*]` |

### 数据规格

- **X轴**: 公司简称 (company)，按 upside 降序排列
- **Y轴**: 上行空间% = `(final_target / current_price - 1) * 100`
- **颜色**: 正值 → `#2ecc71` (绿色)，负值 → `#e74c3c` (红色)
- **标注**: 评级标签 (rating_or_action) 简化映射
  - 买入 → "买"
  - 重点关注 → "关"
  - 高估值风险 → "★"
  - 观察 → "观"
- **Hover信息**: ticker, current_price, final_target, evidence_quality, chain_bucket
- **数据量**: 56 只标的

### 视觉规格

| 参数 | 值 |
|------|-----|
| 画布尺寸 | 1600 × 700 px |
| DPI | 150 |
| Y轴范围 | -80% ~ +80% |
| X轴标签旋转 | 60° |
| X轴字号 | 7pt |
| 零线 | 显示，灰色实线 |
| 网格 | Y轴虚线，alpha=0.3 |

### 核心洞察

1. **多数标的高估**: 70%+ 标的当前市价显著高于模型目标价（上行空间为负）
2. **少数正收益**: 仅运营商（联通/移动/电信）、部分供配电设备（特变电工/明阳电气）存在正上行空间
3. **龙头相对抗跌**: 光模块龙头（中际旭创-18%、新易盛-17%）虽绝对估值高，但模型下行空间有限
4. **风险集中**: PCB材料、IDC运营、算力芯片板块下行风险最集中

### 注意事项

- 目标价基于2026E盈利预测，基本面超预期可能触发重估
- 部分extended标的使用官方披露数据替代券商目标价锚
- 评级标签为简化标注，完整投资逻辑需参考个股估值模型

## 图表2: 各链条PE/PEG估值对比箱线图

| 属性 | 说明 |
|------|------|
| **chart_id** | `chart2_pe_peg_comparison` |
| **标题** | AIDC各板块PE估值分布与PEG对比 |
| **类型** | box (箱线图) |
| **数据来源** | 估值模型 + 市场财务数据 |

### 数据规格

- **X轴**: 7大板块 (chain_bucket)
  1. 光通信 (n=7)
  2. 服务器/网络设备/国产算力 (n=17)
  3. AI PCB/CCL (n=4)
  4. 供配电/能源 (n=7)
  5. 液冷/温控 (n=7)
  6. AIDC/IDC 运营 (n=7)
  7. 算力芯片/存储/网络 ASIC (n=6)
- **Y轴**: 2026E PE = `market_cap_100mn_cny / np_2026e_100mn`，对数刻度
- **箱体**: 中位数、四分位、须线(1.5×IQR)、异常值标记
- **标注**: 板块平均PEG (PE / 营收增速，仅当增速>0时)

### 派生指标

| 指标 | 公式 | 数据源 |
|------|------|--------|
| PE_2026E | 市值 / 2026E净利润 | 估值模型 |
| 营收增速 | (2026E营收 / 2025营收) - 1 | 市场财务数据 |
| PEG | PE / 营收增速(%) | 组合计算 |

### 视觉规格

| 参数 | 值 |
|------|-----|
| 画布尺寸 | 1200 × 700 px |
| DPI | 150 |
| Y轴刻度 | 对数，范围 5x ~ 5000x |
| 箱体颜色 | 按板块区分 (7色方案) |
| 异常值 | 显示，空心圆点 |
| PEG标注 | 箱体上方，粗体 |

### 板块颜色方案

| 板块 | 颜色 |
|------|------|
| 光通信 | `#3498db` (蓝) |
| 服务器/网络设备 | `#e67e22` (橙) |
| AI PCB/CCL | `#9b59b6` (紫) |
| 供配电/能源 | `#f1c40f` (黄) |
| 液冷/温控 | `#1abc9c` (青) |
| AIDC/IDC 运营 | `#e91e63` (粉) |
| 算力芯片/存储 | `#795548` (棕) |

### 核心洞察

1. **算力芯片PE最高**: 中位数~150x，反映国产替代高预期
2. **供配电价值洼地**: PE中位数~36x，相对低估
3. **服务器离散度极大**: 18x~3300x，盛科通信等亏损股拉高极值
4. **液冷PEG最优**: ~3.0x，估值与增速匹配度最好
5. **光模块PEG合理**: 龙头50-57x PE对应60%+增速

### 注意事项

- PE基于2026E一致预期，盈利下修则实际PE更高
- PEG使用营收增速（非净利润增速），因部分公司利润基数异常
- 对数刻度压缩高PE区间视觉差异
- 运营商拉低IDC板块PE中位数

## 图表3: 证据质量分布热力图

| 属性 | 说明 |
|------|------|
| **chart_id** | `chart3_evidence_quality_heatmap` |
| **标题** | AIDC产业链证据质量热力图：直接证据比例 |
| **类型** | heatmap (热力图) |
| **数据来源** | `data/field_evidence_completion_20260701.json` |

### 数据规格

- **行 (7行)**: 证据字段
  1. 收入暴露 (revenue_exposure)
  2. 客户 (customer_or_platform)
  3. 订单 (order_or_backlog)
  4. 产能 (capacity_or_certification)
  5. ASP (asp_or_price_proxy)
  6. 利用率 (utilization_or_yield)
  7. 利润率 (margin_impact)

- **列 (8列)**: 板块
  1. 光通信
  2. AI服务器
  3. PCB材料
  4. 供配电
  5. 液冷
  6. IDC
  7. 算力芯片
  8. 下游应用

- **颜色值**: 直接证据比例 = `count(status=='direct') / total`
- **色阶**: RdYlGn (红→黄→绿)，范围 [0.7, 1.0]

### 板块映射关系

| 证据数据chain_blocks | 热力图标签 |
|---------------------|-----------|
| 网络与光通信 | 光通信 |
| 服务器整机与零部件 | AI服务器 |
| PCB 与上游材料设备 | PCB材料 |
| 供配电与能源 | 供配电 |
| 液冷与温控 | 液冷 |
| 数据中心建设与运营 | IDC |
| 上游算力芯片与存储 | 算力芯片 |
| 下游需求与应用 | 下游应用 |

### 视觉规格

| 参数 | 值 |
|------|-----|
| 画布尺寸 | 1000 × 500 px |
| DPI | 150 |
| 色阶 | RdYlGn, vmin=0.7, vmax=1.0 |
| 单元格标注 | 百分比格式，9pt |
| 文字颜色阈值 | >85%→黑色，<85%→白色 |
| Colorbar | 右侧，标签"直接证据比例" |

### 核心洞察

1. **整体证据质量极高**: 99% (409/413) 为直接证据
2. **利用率字段最弱**: 56/59直接，有2例券商间接、1例代理证据
3. **产能字段次之**: 58/59直接，1例代理证据
4. **光通信/算力芯片最完整**: 头部标的多、信息披露规范
5. **下游应用样本最少**: 仅6家，但证据质量100%直接

### 注意事项

- 热力图反映证据分类的直接性，不代表证据本身质量
- "直接"包括券商研报引用和公司公告
- 仅覆盖59家核心候选，长尾标的证据质量可能更低
- 部分字段(如ASP)的"直接"可能来自券商产业链调研转述

## 图表4: 市值-上行空间散点图

| 属性 | 说明 |
|------|------|
| **chart_id** | `chart4_market_cap_upside_scatter` |
| **标题** | 市值-上行空间散点图：大市值标的相对抗跌 |
| **类型** | scatter (气泡散点图) |
| **数据来源** | 估值模型 + 原始行情数据 |

### 数据规格

- **X轴**: 市值 (亿元)，对数刻度 = `market_cap_100mn_cny`
- **Y轴**: 上行空间% = `upside * 100`
- **点大小**: 日均成交额 (亿元) = `amount_cny / 1e8`
  - 数据来源: `data/raw_market_financials_20260630.json` → `records[*].quote.amount_cny`
  - 仅18只原始目标有真实成交额数据
  - **Fallback**: 扩展标的使用 `market_cap_yi / 50` 作为尺寸代理
- **颜色**: 按 chain_bucket 分类 (7色方案，同图表2)
- **标注**: 前10大市值标的名称

### 视觉规格

| 参数 | 值 |
|------|-----|
| 画布尺寸 | 1200 × 800 px |
| DPI | 150 |
| X轴 | 对数刻度，范围 10亿 ~ 30000亿 |
| Y轴 | 线性，范围 -80% ~ +80% |
| 点透明度 | alpha=0.75 |
| 点边框 | 白色，0.8px |
| 零线 | 灰色虚线 |
| Top-10标注 | 名称，8pt，偏移(5,5) |
| 图例 | 右下角，板块颜色 |

### 核心洞察

1. **大市值相对抗跌**: 市值>5000亿标的模型下行空间普遍小于中小市值
2. **运营商唯一正收益**: 中国移动/电信是大市值中仅有正上行空间的标的
3. **小市值风险最大**: 小市值IDC和液冷标的下行空间-60%~-66%
4. **弱正相关**: 市值越大，模型给出的下行空间相对越小
5. **流动性集中**: 工业富联、中际旭创日均成交额最大

### 注意事项

- 仅18只原始目标有真实成交额数据，其余38只用市值/50近似
- 上行空间基于模型目标价，不代表短期股价走势预测
- 对数市值刻度压缩大市值区间视觉距离
- 点大小为面积映射，视觉感知可能与实际数值有偏差
