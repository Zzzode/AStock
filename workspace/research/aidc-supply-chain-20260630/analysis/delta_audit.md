- prevention_rule_added: A report may be `mechanical PASS / institutional FAIL` when artifacts exist but lack field-level evidence/model/valuation/IC depth; PASS final sign-off is blocked when material residual risks affect core conclusions.

## Failure Map

| Failure mode | Prior behavior | New prevention rule |
|---|---|---|
| Artifact exists but is shallow | Gate could pass on file existence | Artifact contract must include required fields, minimum depth, blocking conditions, reviewer cycle, and verifier check |
| Residual risk conflicts with PASS | Final sign-off could remain PASS | Material residual risks for customer/order/ASP/utilization/source/model/valuation force open findings, waiver, or downgrade |
| Growth model is an EPS proxy table | Could be treated as conditional pass | Applicable tickers require base/growth split, unit/order/ASP/proxy bridge, gross profit, net profit, EPS, scenarios, and current-price-implied growth |
| Value-chain economics stays block-level | Could support valuation language | Core valuation credit requires ticker/subsegment-level economics or no-target-price triage |
| Valuation table lacks anchor depth | Could pass with target table | Valuation must reconcile price/share count, business-method fit, Street anchor, market-implied anchor, and final weights |

## Current Case Disposition

The current AIDC case is a regression specimen. Under the upgraded rules it should no longer be treated as institutionally publishable until the growth model, value-chain economics, customer-chain evidence, and final sign-off are repaired or the affected tickers are downgraded.
