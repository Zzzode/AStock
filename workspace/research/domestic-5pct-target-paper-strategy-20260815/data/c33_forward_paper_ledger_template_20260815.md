# C33 前瞻纸面记录模板

- 状态：`template_only_no_observations`。
- 用途：在 C33 候选规则完成、独立审查通过后，记录连续六个月的前瞻纸面信号、目标、执行质量与对账。空模板不是策略表现，也不代表任何产品已获得操作资格。

## 每月一条记录的必填字段

| 字段 | 记录要求 | 缺失后的处理 |
|---|---|---|
| 规则版本与哈希 | 与冻结的 C33 规则一致 | 整期 `no_action`，不得补用新规则 |
| 信号日期 / 可得时间 | 收盘后形成，精确到时区 | 不得使用同日成交或事后数据 |
| 原始输入与来源哈希 | 每一标的的信号价格/状态、来源和抓取时间 | 不能形成目标 |
| 目标权重 | 所有标的、合计与零权重标的均显式记录 | 不得以相似产品替换 |
| 最早可行动日 | 下一共同交易时段 | 当天、盘中或回补成交均无效 |
| 产品和账户状态 | 最新产品文件、交易状态、权限、最小单位、结算事实 | 相应标的 `no_action` |
| 报价 / IOPV / 价格保护 | 买一卖一、可用 IOPV（如适用）、盘口时间和阈值 | 缺任一交易必需项则 `no_action` |
| 纸面执行 | 限价、申请数量、份额取整、成交/部分成交/未成交原因 | 不得把目标权重写成成交结果 |
| 费用与结算 | 实际可核对的费率、税费、资金/份额可用时间 | 无法核对则冻结下一期新增动作 |
| 对账与独立复核 | 期末状态、差异说明、复核人和异常关闭情况 | 未对账记录不计入连续期数 |

连续六期均完整、规则未漂移且每期独立复核后，才可讨论从 `research_only` 进入 `paper_operable`；这不构成外部操作授权或收益承诺。
