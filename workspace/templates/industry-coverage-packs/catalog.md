# Industry Coverage Pack Catalog

Use one coverage pack before starting a deep industry-chain report. The selected pack must be cited in `analysis/template_brief.md` and `research_brief.md`.

| Pack | Use Case | File |
|---|---|---|
| AIDC | AI data-center infrastructure, AI server, power/cooling/networking/storage/PCB/IDC chain | `workspace/templates/industry-coverage-packs/aidc.md` |
| Semiconductor | Equipment, materials, fabs, design, packaging, EDA/IP, localization | `workspace/templates/industry-coverage-packs/semiconductor.md` |
| Materials | Specialty/electronic materials, gases, chemicals, metals, upstream resources | `workspace/templates/industry-coverage-packs/materials.md` |
| Healthcare | Drugs, devices, CXO, diagnostics, hospitals, pharmacies, healthcare services | `workspace/templates/industry-coverage-packs/healthcare.md` |
| Consumer | Brands, retail, food and beverage, apparel, appliances, services | `workspace/templates/industry-coverage-packs/consumer.md` |
| Cyclical | Commodities, industrial cyclicals, transportation, construction chain, energy, machinery | `workspace/templates/industry-coverage-packs/cyclical.md` |

If no pack matches, write a custom pack inside `analysis/template_brief.md` and label it `custom`, then add a reusable pack to this directory after the case if the pattern is likely to recur.
